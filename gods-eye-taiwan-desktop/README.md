TDX欄位移除顯示Secret／專用儲存／專用測試三按鈕，統一使用底部儲存金鑰。分析三入口改垂直藍／綠／紫，內部主要操作依功能配色。公共運輸合併為「依最新交通資訊進行AI規劃」，刪除直接規劃／修改條件及重複結果清單，保留輸入與路線顏色／粗細；結果進既有AI空間助理，推薦方案自動在同一地圖顯示。

## 首次安裝瀏覽器版（推薦）

### 必要環境

- Windows 10／11 64 位元。
- [Git](https://git-scm.com/downloads/win)。
- [Node.js](https://nodejs.org/en/download)：24.14 以上的 24.x，或 26.x；內含 npm。
- Google Chrome、可用的 WebGL 與音訊裝置。
- 網路：首次下載上游及相依套件、使用線上底圖與 API 時需要。

瀏覽器版不需要 Rust、Visual Studio 或 Tauri EXE。

在專案資料夾開啟 PowerShell，執行：

```powershell
node .\scripts\install-browser.mjs
```

安裝程式依 `UPSTREAM.lock` 取得鎖定上游、套用台灣版、安裝套件及建立正式介面；所需時間取決於網路與電腦。若已有安裝工作區會停止，不刪除既有設定。首次安裝完成後雙擊：

```text
啟動上帝之眼-瀏覽器版.bat
```

它會啟動／沿用本機圖資服務，再以 Chrome 開啟 `http://127.0.0.1:4175`。金鑰與網站資料使用同一個本機入口保存；請避免切換到不同連接埠。啟動紀錄在 `logs/browser-launch.log`。

## 服務與金鑰

右上齒輪 →「設定」→「服務與 API 金鑰設定」，輸入需要的服務金鑰並儲存。未設定必需金鑰時，按「載入」會提示「未輸入金鑰」。

|服務|用途|
|---|---|
|Google Maps／Cesium ion|Google 擬真3D、Bing影像及全球地形；可用資產依金鑰權限與服務方案|
|TomTom|地標搜尋、行車路線與即時路況|
|OpenRouter|文字對話與圖層AI分析，可選模型與自訂回覆風格|
|Gemini Live|即時語音與地圖操作，模型 `gemini-3.8-live`|
|AISStream、NASA FIRMS、OpenSky等|船舶、熱點、飛機等各來源功能|

金鑰以 Windows DPAPI CurrentUser 加密保存在本機使用者目錄；關閉程式後可沿用。AI／TomTom長效金鑰由本機服務保管，不回傳前端或匯出JSON。Google／Cesium瀏覽器SDK必須使用對應憑證，請在供應商設定適當權限。服務額度與可用性以供應商為準，「對話無上限」僅代表取消本程式次數限制。

## 即時交通、導航與CCTV

- TomTom使用真實車速相對於順暢速度的比例，綠色順暢、黃色變慢、紅色壅塞、紫色封路；路況細線一般1.3像素，封路2像素。
- 移動點位使用與車流線相同的地形／3D 路面貼面方式，避免固定地形高度造成傾斜視角錯位；以貼面圓點動畫依路況比例分組呈現快慢。點位是車流示意，非個別車輛定位或車輛數量；封路不產生移動點位。路況每兩分鐘更新，移動視野會查詢新區域。
- 起訖點可用TomTom搜尋，路線顯示名稱、距離、時間與轉向指示；「行車視角沿路線」可播放沿路低角度相機，不需GPS。目前以路線行進示意觀察，不提供 GPS 行車導航。
- 「分析」中的CCTV可載入全台國道目錄、圈選或一鍵開啟總覽。每頁12路同時更新，可換頁、暫停、重連與關閉；來源離線逐路提示，不用合成影像代替。全台目錄不代表同時開啟1800多路。

- AI 選項新增「AI語音助理功能說明與風格」：功能、範例、限制、可伸縮風格欄位，以及本機持久設定。語音與文字助理的風格分開保存，不相互覆蓋。
- 語音可辨識「載入宜蘭縣的 3D 建物圖資」及常見口語／ASR 寫法。明確圖資＋縣市直接執行；間接需求會提出候選，歧義時先確認；可沿用已說出的範圍並回覆「我會載入…」「我已完成…」。多項圖資逐項回報。
- 地點使用五秒矩形地點標籤；同座標不重複新增，可設定下一個語音指令開始時提前清除。模糊地點列出候選，地點／路線／視角等工具在執行前回報意圖，完成後回報實際結果。
- 語音角色涵蓋程式介紹、台灣地理歷史，以及使用公開新聞 RSS 工具的新聞／輿情分析。查詢結果不代表全體民意；來源連結、日期及標題顯示於 AI 面板。地圖畫面分享需勾選，要求時才傳送目前 Cesium 畫布，不包含金鑰或其他視窗。
- 標註與量測新增「運鏡」，放於量測距離下方：目前改為手繪軌跡／自由空拍兩模式。手繪確認路徑後進入拍攝手法與 AI 修正規劃，通過幾何檢查才開拍；自由空拍操作與 Esc 行為見本頁 v25 說明。這是本機 GIS 視覺工具，不是實際無人機航線或工程安全認證。

## 電影空拍與 CCTV 統一成果（目前操作）

### 電影空拍：只保留兩個模式

「標註與量測 → 電影空拍」開啟獨立浮動視窗；標題列 `?` 展開說明及操作步驟。

- **手繪空拍軌跡**：按開始手繪，在地圖按住左鍵畫線 → 確認路徑 → 填寫拍攝手法／範例 → AI 修正規劃 → 本機 3D 障礙與連續路段檢查 → 手動開拍。沒有 AI Key 時提供本機規劃；未知障礙不允許開拍。拍攝時軌跡線隱藏。
- **自由空拍**：點地圖放置原創四旋翼 3D 模型，可拖曳調整 → 確認並開始拍攝。W/S 前後、A/D 左右、I/K 升降、J/L 加速減速、滑鼠調整朝向；Esc 停止拍攝並回到預覽，不自動下載。
- 使用目前的 Cesium 3D 場景，不隱藏 NLSC 建物或改成假地形。以機身體積、安全距離、連續路段查詢檢查地形、已載入 3D Tiles 及已註冊碰撞模型。最高細節查詢不足或來源更新時保守懸停；依來源幾何檢查，無法保證官方未提供的障礙。
- 只錄製地圖畫布，使用本機 `captureStream`／`MediaRecorder` 輸出 WebM，不錄製浮動控制視窗。影片可預覽、下載或儲存至「記錄」；匯出 ZIP 包含影片、飛行 GeoJSON 及時間／參數／碰撞檢查摘要。
- 本機規劃、手動運鏡與錄影不需 AI API Key、必要 API 費用或訂閱。選用 AI 規劃只傳有限拍攝參數需求，不能執行模型產生的 JavaScript。

### CCTV：一鍵辨識，成果統一進入 AI 空間助理

「分析 → CCTV 監看」選目前視野、圈選或全臺目錄；每頁最多 12 路。監看視窗只保留選畫面、影像、**一鍵辨識**與執行狀態。

- 點擊時立即固定 Frame A 與請求 ID，辨識中同一鏡頭不能重複送出；持續監看及地圖操作不被鎖住。
- 優先本機 YOLOX Tiny／Nano、WebGPU → WASM；模型隨程式提供，沒有 Key 也可辨識。資源保護會降低同時工作數、使用 Nano；空拍／錄影優先於背景 CCTV。
- 本機成功不送外部 AI。Tiny／Nano 失敗時才使用已設定的免費影像模型備援；全部失敗如實回報。此備援會把固定截圖傳送至已設定的外部服務。
- 完整結果自動叫回**同一個 AI 空間助理**，保留既有對話和未送出的文字；含相同辨識截圖、來源、取得時間、來源提供的攝影機時間、六類物件數量、壅塞估計及辨識方式。截圖可放大、切換辨識框。
- 可在 AI 空間助理繼續提問。一般問題只用既有統計；事故、積水等影像問題才再檢查同一張固定截圖。無法判定時不補造結果。
- 再按該路一鍵辨識會新增新的辨識結果；AI 空間助理「清除／儲存對話」統一管理。CCTV 紀錄匯出 ZIP 以獨立 JPEG 加 Markdown／JSON 保存，避免把巨大 base64 塞入 Markdown。
- 統計為 AI 視覺估計，不代表官方交通統計、車速或連續通過量；尚未加入 ByteTrack 或 LoRA。

### 浮動視窗、NLSC 與路線

電影空拍、CCTV、AI 空間助理使用同一套非模態浮動視窗管理，可拖曳、調整大小、縮小、展開、隱藏、重新叫回及點擊置頂。縮小／隱藏保留工作；停止保留介面，關閉停止並釋放資源；位置與尺寸保存在瀏覽器，越界會拉回。

NLSC 建物與台灣 3D 地形地貌可同時顯示：建物顯示期間地形採真實高度 **1 倍**，避免預設 3 倍地形遮住官方建物；隱藏建物後恢復原倍率。詳細載入預設 SSE 2，資源壓力時協調快取與細節；縣級遠景／官方覆蓋缺漏／目前串流 LOD 均不等於全棟清單。請放大街區並查看下載、失敗、記憶體限制狀態。白模可切換回原材質，不改官方座標。
