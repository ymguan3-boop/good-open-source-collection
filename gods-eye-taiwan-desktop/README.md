# 上帝之眼・台灣版

以 God's Eye View 與 CesiumJS 為核心的繁體中文 3D 地圖、圖資管理及 AI 空間分析程式。修改者：官毅明。

本專案提供原始碼與本機安裝流程。推薦使用 Windows 瀏覽器版；亦保留 Tauri 桌面版。本機服務只綁定 `127.0.0.1`，不可直接雙擊 HTML，也不是 GitHub Pages 純靜態網站。

## 下載

[程式資料夾](https://github.com/ymguan3-boop/good-open-source-collection/tree/main/gods-eye-taiwan-desktop)

可在倉庫首頁選「Code → Download ZIP」（下載壓縮檔），解壓縮後進入 `good-open-source-collection-main\gods-eye-taiwan-desktop`；或執行：

```powershell
git clone https://github.com/ymguan3-boop/good-open-source-collection.git
cd good-open-source-collection\gods-eye-taiwan-desktop
```

## 首次安裝瀏覽器版（推薦）

### 必要環境

- Windows 10／11 64 位元。
- [Git](https://git-scm.com/downloads/win)。
- [Node.js](https://nodejs.org/en/download)：24.14 以上的 24.x，或 26.x；內含 npm。
- Google Chrome、可用的 WebGL 與音訊裝置。
- 網路：首次下載上游及相依套件、使用線上底圖與 API 時需要。

瀏覽器版不需要 Rust、Visual Studio 或 Tauri EXE。

在專案資料夾開啟 PowerShell，執行：

```powershell
node .\scripts\install-browser.mjs
```

安裝程式依 `UPSTREAM.lock` 取得鎖定上游、套用台灣版、安裝套件及建立正式介面；所需時間取決於網路與電腦。若已有安裝工作區會停止，不刪除既有設定。首次安裝完成後雙擊：

```text
啟動上帝之眼-瀏覽器版.bat
```

它會啟動／沿用本機圖資服務，再以 Chrome 開啟 `http://127.0.0.1:4175`。金鑰與網站資料使用同一個本機入口保存；請避免切換到不同連接埠。啟動紀錄在 `logs/browser-launch.log`。

### 交由 Agent 安裝

可把本資料夾交給 Codex 或 Claude Code，輸入：

> 請讀取 AGENTS.md，使用 scripts/install-browser.mjs 安裝瀏覽器版，再啟動「啟動上帝之眼-瀏覽器版.bat」。請確認正式介面可開啟及圖資可載入，保留既有設定與金鑰。

### Tauri 桌面版（選用）

另需 Rust stable／Cargo、Microsoft C++ Build Tools 及 WebView2。由 Agent 依 `AGENTS.md` 檢查環境，再執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\agent-install-windows.ps1
```

桌面捷徑為「上帝之眼-台灣版」，圖示使用 `branding/gods-eye-taiwan-v4.ico`。本次修改已完成瀏覽器版建置、互動畫面及 CCTV 免費模型 API 檢查；Tauri EXE 尚待另行驗收。瀏覽器可用不代表防毒對 EXE 的偵測屬誤判。

## 更新既有安裝

先匯出 JSON 專案及需要的對話紀錄，再關閉程式與本機服務。建議將新版原始碼放入另一個全新資料夾，執行上述首次安裝流程，再匯入專案；本機 DPAPI 金鑰仍存於同一 Windows 使用者的 LocalAppData。請保留舊資料夾直到確認專案、網站資料與圖資正常，對話紀錄不會由資料夾複製自動搬移。

## 服務與金鑰

右上齒輪 →「設定」→「服務與 API 金鑰設定」，輸入需要的服務金鑰並儲存。未設定必需金鑰時，按「載入」會提示「未輸入金鑰」。

|服務|用途|
|---|---|
|Google Maps／Cesium ion|Google 擬真3D、Bing影像及全球地形；可用資產依金鑰權限與服務方案|
|TomTom|地標搜尋、行車路線與即時路況|
|OpenRouter|文字對話與圖層AI分析，可選模型與自訂回覆風格|
|Gemini Live|即時語音與地圖操作，模型 `gemini-3.8-live`|
|AISStream、NASA FIRMS、OpenSky等|船舶、熱點、飛機等各來源功能|

金鑰以 Windows DPAPI CurrentUser 加密保存在本機使用者目錄；關閉程式後可沿用。AI／TomTom長效金鑰由本機服務保管，不回傳前端或匯出JSON。Google／Cesium瀏覽器SDK必須使用對應憑證，請在供應商設定適當權限。服務額度與可用性以供應商為準，「對話無上限」僅代表取消本程式次數限制。

## 本機新增：對話記錄、標籤與查核行程

- 工具列「成果」已改為「記錄」。在 AI 空間助理按「儲存對話」，會以台灣日期時間命名 MD，暫存在目前瀏覽器；點檔名可開啟能調整大小、可關閉的檢視窗。單筆匯出 MD，多筆／全部匯出 ZIP。原有 JSON 專案操作仍在「專案」。
- 自訂風格同時寫入網站儲存與瀏覽器資料庫，讀回確認後才顯示成功；重新開啟同一網址與瀏覽器設定檔時讀取較新的設定。無痕模式或清除網站資料不保證保留。
- 「標註與量測 → 地圖文字標籤」可輸入文字、選字體、顏色、一般／粗體及字級，再點地圖放置；每個標籤項下可修改，JSON 專案保留標籤樣式。提供標楷體、新細明體、微軟正黑體與 IBM Plex Sans TC，未安裝的字體會替代。
- 「分析」主面板只保留行車路線與導航、CCTV 圈選多畫面總覽。路線可任意新增、刪除及排序中途點，選汽車／機車；機車模式避開高速公路，但供應商資料仍須依現地交通規定確認。
- AI 查核行程：輸入起點與需求 → 手動增加停靠點或查詢學校候選名單 → AI 建議順序 → 確認並套用 → 規劃路線。TomTom 逐段計算距離、時間及行進路線；候選學校最多 100 處，並非官方完整清冊，可自行補上。AI 順序建議不是最短路線保證。
- CCTV 總覽預設「自動選擇免費模型（失敗自動替換）」，直接按指定畫面的「AI 辨識車輛／車流」即可。依最新模型目錄篩選可接收影像且免費的模型，遇限流、逾時或錯誤自動替換其他免費模型；也可指定優先免費模型。請求依序執行，失敗模型暫時冷卻，供應商價格上限設為零，不會改用付費模型。分析當張官方影像、顯示取得時間、實際模型與替換次數，結果也加入 AI 對話。單張可估計可見車種與擁擠程度，不能計算連續流量或實測速度；模型可能誤判。
- 飛機觀察卡增加航空公司、機型、註冊編號、起訖機場、高度、速度、航向及位置，未回傳欄位顯示「來源未提供」。
- NLSC 建物載入／再次顯示時配合真實地形，取消地形誇大；目前為 Google 擬真 3D 時切換 NLSC 正射影像，避免兩套建物重疊。保留官方座標，高程微調只影響展示。修正較低建物被全球地形遮住的問題，並提高細節載入完整性；建物子圖層的「說明與分析」顯示下載、處理、已載入與失敗圖磚狀態。圖磚數不等於建物棟數；來源未建檔的建物仍無法補出。官方 DTM 樣點本身不等於地形表面。

本次更新為 v17，修正語音範圍回答無法接續載入及重複詢問，保留 v16 的語音載入範圍確認、可拖曳飛機視窗與地圖標籤、修正飛機視角切換、對話免費模型輪替、緊湊記錄排版，以及重啟後沿用自訂風格。本次驗收見 [修改紀錄 v17](docs/voice-scope-fixes-v17-20261002.md)，前次修改見 [修改紀錄 v16](docs/browser-fixes-v16-20261002.md)；前次功能見 [修改紀錄 v15](docs/browser-fixes-v15-20261002.md)。

## 本機新增：圖層收合、樣式與台灣地形

- 「圖資 → 行政區界 → 說明與分析」可調整框線顏色、粗細（1～8 像素）及是否顯示框線；匯出 JSON 會保留樣式。
- 「專案」的第一層專案／目前工作區，以及「圖資」中的 JSON 專案名稱，均可點擊箭頭收合所有子圖層；收合狀態記在目前瀏覽器，不會隱藏地圖上的圖資。
- 「全臺參考圖 → 說明與分析」可直接載入道路中心線、河川／水系中心線、水域面及鐵路，沿用選定載入範圍。道路、水文是隨附 OSM 固定版；鐵路是官方開放資料，參考圖磚本身不是向量。
- 「影像與擬真底圖」新增 NLSC 臺灣通用正射影像（PHOTO2）與臺灣通用電子地圖（EMAP），免輸入金鑰、需網路；服務代碼與最高圖磚層級依 [NLSC 官方 WMTS 說明](https://maps.nlsc.gov.tw/S09SOA/pro/Wmts_ajax_main.jsp)。
- 「全球地形 → 台灣 3D 地形地貌」以真實地形、NLSC 正射影像、坡面光影及青色縣市界呈現山脈、河谷與平原。可調整高程視覺放大倍率（1～6 倍，預設 3 倍）；隱藏或移除恢復先前底圖，切換其他底圖自動退出地形展示。展示倍率不修改原始高程，不替代官方 20 公尺 DTM。
- 本次變更只在本機；修改及驗收紀錄見 [本機修改紀錄](docs/browser-fixes-v13-20261002.md)。

## 本機新增：飛機觀察與語音圖資操作

載入「圖資 → 飛機即時動態」後，點選地圖上的飛機，畫面會出現觀察卡：

- **第一人稱**：從所選飛機沿航向觀察，沿用原版駕駛艙鏡頭與資料追蹤。
- **第三人稱**：從飛機外部跟隨，可拖曳旋轉、縮放；保留所選航機，串流模型未顯示時仍有同步位置的飛機標示。拖曳觀察卡標題可自由移動視窗。
- **停止觀察**：退出鏡頭追蹤；若觀察功能自動開啟原版飛機模式，也會還原先前模式。

位置與飛行狀況依 OpenSky／ADS-B 回傳；延遲資料的移動為推估，並非飛機攝影機的實況影像。飛機未在來源清單或已離開範圍時，會提示無法觀察。

重新整理程式，再停止／重新啟動 Gemini Live 麥克風，即可使用新增的語音工具。例如：

| 需求 | 語音範例 |
| --- | --- |
| 載入指定圖資 | 「載入飛機即時動態」、「載入縣市界」、「載入 TomTom 即時交通」 |
| 隱藏指定圖資 | 「隱藏道路中心線」 |
| 切換圖層顯示 | 「切換河川水系中心線的顯示狀態」 |
| 切換底圖 | 「切換到 NLSC 臺灣通用正射影像」 |
| 一鍵載入 | 「一鍵載入所有內建圖資」 |
| 一鍵隱藏 | 「一鍵隱藏所有圖資」 |

語音載入／更新前會先確認正式縣市或全台灣範圍；例如「載入全台灣道路中心線」。未說明範圍時會先詢問；只有全球或全臺來源時，會解釋涵蓋範圍與替代建議，確認後才載入，不會自行猜範圍。若明確說「目前範圍」，才沿用工具列範圍。一鍵載入也先統一確認範圍，包含內建向量、官方 DTM、NLSC 建物與全臺參考圖；即時資料及底圖可另外指定。隱藏圖資時保留既有 Google 擬真 3D 底圖，語音連線保持啟用。執行結果會核對狀態，缺少金鑰、部分資料及來源失敗會回報實際原因。本版已檢查實際航機的第一／第三人稱往返切換；真實麥克風多輪語音範圍確認尚待驗收，詳見修改紀錄。


## v16 操作與設定保存

- **地圖標籤**：按住地圖上的文字拖曳，放開完成；相機不會跟著標籤移動。位置（經緯度與表面高度）同步寫入圖層 GeoJSON，匯出 JSON 專案可保存新位置。舊的二維標籤仍可讀取；拖曳後改用所選表面的高度。
- **自訂風格**：AI 空間助理 → 風格 → 輸入 → 儲存風格。啟動時先完成讀取，再開放風格欄位；瀏覽器 localStorage、IndexedDB 與本機備份以時間比對最新版本。本機備份位於 `%LOCALAPPDATA%\GodsEyeTaiwan\response-style.json`，相同 Windows 使用者重啟或切換啟動入口可沿用。舊瀏覽器仍保有的風格會自動遷移；已被清除的舊文字無法重建，可重新輸入並儲存一次。
- **免費模型輪替**：空白文字、只有思考內容、逾時、429 或供應商中斷都會自動嘗試清單內其他免費文字模型。失敗片段會清除，不會混入下一個模型回答。單次嘗試最多45秒、等待首段文字20秒，整體輪替最多4分鐘；可用模型都失敗時如實回報，401則要求修正金鑰，不無限重試。備援採即時免費清單並設定價格上限0；免費額度與服務可用性仍由供應商決定。
- **記錄排版**：勾選框、檔名、日期及匯出／刪除按鈕使用緊湊排列；預覽不再把每個 Markdown 空白行展成額外高度，程式碼區塊保留原始換行。MD／ZIP 匯出仍保留原始對話內容。

套用更新後，關閉舊程式及本機服務，再用原啟動入口重新開啟；若仍看到舊畫面，重新整理頁面。需要建立新的本機風格備份時，在新版按一次「儲存風格」。

## 即時交通、導航與CCTV

- TomTom使用真實車速相對於順暢速度的比例，綠色順暢、黃色變慢、紅色壅塞、紫色封路；路況細線一般1.3像素，封路2像素。
- 移動點位使用與車流線相同的地形／3D 路面貼面方式，避免固定地形高度造成傾斜視角錯位；以貼面圓點動畫依路況比例分組呈現快慢。點位是車流示意，非個別車輛定位或車輛數量；封路不產生移動點位。路況每兩分鐘更新，移動視野會查詢新區域。
- 起訖點可用TomTom搜尋，路線顯示名稱、距離、時間與轉向指示；「行車視角沿路線」可播放沿路低角度相機，不需GPS。定位導航另需使用者授權裝置位置。
- 「分析」中的CCTV可載入全台國道目錄、圈選或一鍵開啟總覽。每頁12路同時更新，可換頁、暫停、重連與關閉；來源離線逐路提示，不用合成影像代替。全台目錄不代表同時開啟1800多路。

## 專案、標註、分析與AI

- 匯入／匯出JSON，專案圖層可切換顯示、排序、刪除及改色。「記錄」保存 AI 對話 MD；清除網站資料會移除暫存，請另存下載檔。舊版成果的 JSON 資料仍保留於資料庫，未列入新的對話紀錄面板。
- 標註與量測：先選工具、填色、框線與粗細，再繪製；圓形可指定半徑，多邊形顯示頂點。每個成果可排序、刪除，說明與AI分析置於可展開的子層級。
- 完成繪製後，手動加入已載入圖資、確認子圖層，再計算／AI解析。缺少可計數建物向量時顯示未知，不把Google擬真3D影像直接當作可計數的建物清冊。
- 全球地形與官方20m DTM分開取樣／標示，未取得真實高程時不填入虛構數據。官方DTM為大型選用下載，相關腳本在 `scripts/install-official-dtm.ps1`，不隨Git打包。

## v17 語音指定圖資與區域

- 同一句話包含圖資與區域時直接載入，不重問。例如「請載入宜蘭縣道路中心線」「載入全台灣河川水系中心線」。
- 只說「載入道路中心線」時詢問範圍；回答「全台灣」「宜蘭縣」或其他正式縣市名稱，即接續原圖資，不必重講名稱。
- 待補範圍請求保留兩分鐘；說「取消」或停止語音會清除。重新指定另一圖資時，以新請求為準。
- 辨識繁簡字及有限已知同音誤字，不任意推測未知地區；支援官方22縣市。
- 來源只有全球／全臺，或縣市沒有服務時，仍說明限制及建議；「載入」沿用固定版，明確「更新」才查線上。
- 更新後請重新整理程式，停止並重新開啟語音助理，讓頁面載入新的控制器。

- 可以說「能不能幫我載入宜蘭道路中心線」「請載入全台灣水系」，已提供圖資與區域就直接執行。
