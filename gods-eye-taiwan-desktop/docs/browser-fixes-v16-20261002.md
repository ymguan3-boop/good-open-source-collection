# v16 修改與驗收紀錄（2026-10-02）

## 本次需求

語音載入先了解地理範圍；航機狀態卡可拖曳、第三人稱不消失；地圖標籤可拖曳；對話失敗自動輪替免費模型；記錄緊湊排列；重啟後沿用自訂風格。其餘既有圖資、工具及資料來源保留。

## 修改

1. 語音工具增加 scope 與來源涵蓋說明，在 host 比對使用者逐字稿。未指定／否定的範圍、同回合自行接受建議、未知縣市均不會直接載入。全球／全臺來源可在解釋後由使用者確認採用並定位原地區。NLSC 縣市服務不存在時先給建議。變更範圍的「載入」仍用固定版，明確「更新」才查線上資料。
2. 航機卡標題使用指標擷取拖曳，限制在視窗內。第一人稱模式啟動後重新取得原航機；第三人稱不銷毀追蹤選取。小型飛機標示同步上游顯示位置與航向，模型未顯示也不會只有框線。
3. 只攔截自訂標籤的拖曳；表面高度、實體位置與 GeoJSON 同步。相機停用至最後一次拖曳輸入消化後再恢復；取消或移除圖層時也還原。既有二維標籤可讀取，新位置保存三維座標。
4. 免費文字模型清單動態取得，過濾安全判斷／嵌入等非對話模型，價格上限0。空白、思考內容、429、HTTP失敗及中斷依序換模型。SSE reset 清除失敗片段，避免串入下一個回覆；總時間4分鐘，每模型45秒，無首段文字20秒換下一個。原生版本保留 Rust 金鑰來源，也改成逐模型輪替。所有模型失敗時回報，不宣稱成功；401需修正金鑰。
5. 記錄清單改成緊湊兩行，勾選框固定14像素。預覽略過多餘空白行並縮小標題間距，程式碼原始換行保留；不修改舊 MD 的內容。
6. 風格先完成啟動讀取，避免欄位先顯示空值；保存到瀏覽器兩處與 Windows 使用者設定，以 updatedAt 選最新，原子寫入本機備份。舊風格仍存在時自動遷移，無法重建已清除的舊文字。
