## 實作

- 三個非 Modal 浮動視窗沿用 Floating Panel Manager。駕車、CCTV 與公共運輸可同時存在，縮小／隱藏保留工作；關閉停止相關工作。
- 表單與自然語言共用 TripPlanningRequest，十個範例只填入文字，不直接規劃。地點歧義需選候選，時間與停留確認後查 TDX。
- 固定 action 的 `/api/taiwan/ai/tdx` 端點管理 OAuth、快取、取消、時限及免費 AI 需求理解。金鑰沿用 Windows DPAPI，不回讀明碼。AI 不生成班次、票價、路徑或即時車輛位置。
- 只有核實 Shape／實際道路線形可播放。未知資料不補假直線、不補零票價。旅程按路段自動換七種 GLB，四視角、1／2／5／10倍速、前後段與暫停。路線顏色／粗細 localStorage 保存。
- 遠距模型以像素尺度與純顯示抬高避免埋入地表，原地理路線不變。高度取樣排除當前與退役模型，paused 狀態只在鏡頭變更時更新；取樣至少500ms間隔，Governor 高負載降至10fps更新。

## 当前 adapter 限制

純WALK／BIKE的MaaS規劃尚不支援，需至少一種公共運輸。公車／自行車票價未知；臺鐵車種票種不足時未知。高鐵／捷運核實成人一般單程票；不能假設適用所有票種。歷史／天候／道路風險未提供，不編造風險數值。跨分支或沒有唯一可核實Shape時禁止假線形播放。詳見 backend adapter 報告。
