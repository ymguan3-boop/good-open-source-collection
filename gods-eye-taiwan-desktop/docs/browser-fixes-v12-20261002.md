# v12 瀏覽器修正與發布紀錄

日期：2026-10-01至2026-10-02；對應鎖定上游 b210ab0fe4d71c7faa0268134e0aa5f3c53fc7fe。

## 完成修改

1. 道路、水系、海岸線不再從全台均勻抽取少量圖徵。以0.1度索引查找視野相交的完整線段，使用批次GroundPolylinePrimitive。街區視野跨度不超過0.16度時顯示全部相交線段；區域／全台視野依道路／水系分類顯示連續幹道與主要河川。完整來源向量供AI與空間分析，原始幾何不切短。移動相機、改色、顯示／隱藏會重建或停用繪圖；新幾何完成前保留舊畫面。
2. 即使手動Overpass更新，完成後也改用視野線段繪製；來源失敗分區仍明示部分資料。舊直接載入入口不再截掉分析資料或簡化線型。
3. 圖資目錄新增「行政區界」群組：22縣市界與368鄉鎮市區界，各自可選縣市／全台、隱藏、改色與移除。鄉鎮主檔TOWN_MOI_1120317，國土測繪中心公開ZIP於2026-10-01下載。EPSG:3824作EPSG:4326顯示，約5公尺顯示簡化。含22縣市與外島；宜蘭12鄉鎮市。
4. TomTom一般路況線5像素改為1.3像素、封路7像素改為2像素。加入原版風格PointPrimitive移動點位，依即時交通速度比例示意快慢，封路不移動，隱藏／刪除停止播放。點位非逐車定位或車輛數量；路況仍每兩分鐘更新及隨視野重查。
5. 車流初始化不逐頂點同步讀取3D表面高度，避免大量GPU讀取導致密集街區卡住；使用已載入地形高程加2公尺示意點。道路路況細線仍貼3D場景。
6. 新增node scripts/install-browser.mjs首次安裝流程，瀏覽器模式不需Rust；原有PowerShell檔案保存UTF-8 BOM，以支援Windows PowerShell中文解析。上游準備遇既有工作區會停止，避免自動刪除既有圖資。
7. 更新台灣版README、選用Whisper後端README及遠端倉庫根README，全部以繁體中文說明下載、安裝、更新、操作、版本與限制。
