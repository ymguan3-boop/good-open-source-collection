# 2026-10-01 瀏覽器版更新：手動圖資分析與對話設定

## 本次完成

1. imagegen 以既有藍金科技風重製長方形「工具列」，展開、收合同尺寸；左側連續排列並隨視窗高度縮放。
2. AI 空間助理提供清除對話、自訂風格、重訂與保存。風格存在目前瀏覽器，後續 OpenRouter 回覆套用；清除中止當前請求，舊請求不能把訊息加回。標題與粗體以安全的 HTML 格式顯示；模型 HTML 先跳脫。請求使用 reasoning.exclude，僅呈現最後回覆。
3. 成果刪除直接移除 IndexedDB 紀錄，取消復原功能。此前已標記刪除的紀錄在成果頁清理；下載檔與目前開啟專案各自保存。
4. 專案各向量圖層展開後可調填色、框線顏色與粗細；地圖立即套用，JSON 保留樣式。地面多邊形框線採獨立折線，可顯示不同粗細。
5. 圖資加入一鍵隱藏，停用即時資料、隱藏工作區向量、地形與 NLSC 模型，保留 Google 擬真 3D 的顯示狀態。
6. 繪製先選樣式、框線與粗細。圓形點中心後確認半徑再完成。完成只保存幾何，不自動做 DTM 或建物統計。

## 新分析流程

選擇繪製工具及樣式 → 完成繪製 → 展開該圖層 → 加入已載入圖資 → 勾選並加入 → 檢查子圖資 → 確認圖資 → 計算並 AI 解析。

- 子圖資可移除、隱藏及排序；變更後清除過期計算與解讀，需重新確認。
- 向量擷取相交圖徵並保留原始幾何；路徑採30m走廊；每項上限20,000筆，來源部分或無法處理圖徵會標示部分資料。
- 底圖、即時服務及3D模型以來源參照加入，不複製整個串流模型。分析來源列控制是否納入計算；原始服務的畫面開關仍在圖資來源列。
- 官方DTM參照按繪製範圍讀本機2025原始20m格網，畫面樣點的數量不等同分析樣點數；匯入DTM只統計已加入的高程點。
- NLSC採官方同縣市分棟服務，BUILD_ID去重及中心落於範圍內計數。上限2平方公里／80葉圖磚／180MB；缺漏或超限維持部分／未知，非現況建物清冊。
- 來源、子層關係、確認狀態、樣式、計算結果與AI解讀隨JSON保存。即時更新保持手動啟動。

## 修正 DTM 邊界問題

宜蘭縣官方行政界含遠處離島，原始縣市外框會超過本島DTM查詢上限。現在保留完整行政界，僅將DTM請求與本島格網涵蓋範圍取交集；範圍完全不重疊時顯示無資料，不改為零或載入其他地區。

- Vite正式build通過；11個來源檔與部署副本SHA-256一致。保留既有大型bundle與Tauri匯入警告。
- 真實OpenRouter：自訂粗體結論與三點建議已套用；標題為HTML heading、粗體為strong，沒有原樣輸出###或**。
- 宜蘭DTM手動載入成功：5,866顯示樣點，縣市大範圍抽樣間距960m；分析另讀20m原始格網。
- 繪製半徑80m圓形：20,091.84m²，周長502.57m；手動加入DTM及宜蘭NLSC並確認後，讀42個分棟圖磚，89棟模型建物；52個DTM樣點，高程6.40至7.42m、平均6.76m。真實AI取得同一89棟與高程結果。
- 完成幾何前不啟動範圍統計；尚未確認時分析鍵停用。隱藏分析子來源後，確認失效、舊結果移除、分析鍵重新停用。
- 實際匯出再從成果載入：5向量／參照層加1服務層，包含圓形、兩個分析輸入、89建物中心；框線#00ffcc／5px、填色、確認、52點與89棟、AI解讀均保存並還原。
- 原7層GeoLibre專案可展開調色；高改善潛力層填色改#00aaff、框線#ff00aa／4px，實體下載JSON保留customized樣式。
- 一鍵隱藏後Google擬真3D仍為已載入，地圖保留Google影像與來源標示。
- 清除對話控制：用隔離的合成狀態執行同一處理程式，確認abort、訊息／草稿／未讀清空、代次遞增。刪除紀錄處理程式以隔離資料庫替身確認使用delete而非軟刪除；未對既有成果紀錄做不可復原的驗收刪除。
