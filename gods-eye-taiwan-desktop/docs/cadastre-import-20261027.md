# 地籍圖（本機匯入）— 2026-10-27

宜蘭縣地籍圖（內政部地政司 shapefile，使用者提供）以**本機資料庫**方式加入，不內建於程式、**不隨 GitHub 發布**（`data/local` 已列入 `.gitignore`）。

## 匯入

```powershell
# 1. 解壓縮（Windows 內建 tar 可讀 RAR）到全新資料夾
tar -xf G宜蘭縣地籍圖.rar -C data\local\cadastre-incoming\extract
# 2. 檔名需為 cadastre.shp / .dbf / .shx / .prj / .cpg（本次已更名）
node scripts\build-cadastre.mjs --shp data\local\cadastre-incoming\extract --db data\local\cadastre-yilan.sqlite --villages data\local\yilan-villages.geojson --source-file data\local\cadastre-incoming\yilan-cadastre.rar
```

來源檔需為 EPSG:3826（TWD97 / TM2 121）Polygon shapefile，含 PMNO（母地號）、PCNO（子號）、SCNO（段代碼）、UNIT、DATE、AA10（面積）欄位。腳本輸出 SQLite（地號幾何為 WGS84 Int32 微度 BLOB＋R*Tree）、來源檔 SHA-256 與匯入時間。

## 本次資料

- 532,377 筆地號，總面積約 2,120 平方公里（宜蘭縣全境）；最新資料日期民國 115 年 5 月 1 日；各地號另有自己的資料日期。
- 驗證：宜蘭市 28,549 棟建物中 28,547 棟中心落在某一筆地號內；壯圍鄉 10,318 棟中 10,316 棟。
- `UNIT` 是地政事務所代碼（GA／GB），**不是鄉鎮市**；資料沒有地段名稱（只有段代碼），也沒有所有權人。

## 功能

- 圖資 → 獨立群組「**宜蘭縣地籍圖**」（不在「宜蘭縣OSM+實價登錄 3D建物」內）：12 個鄉鎮市各一列，可分別**載入／顯示／隱藏／移除／前往**，上方一列可全部顯示或隱藏；已載入的鄉鎮市與顯示狀態下次開啟會還原。
- 地號線：高度約 4 公里內才畫畫面中心附近（約 0.9 公里見方、最多 5,000 筆）的貼地地號線，500 公尺內標示地號。
- 點建物：建物資訊的「地籍」顯示建物**中心點**所在地號、段代碼、登記面積、資料日期。建物跨多筆地號時只顯示中心所在的一筆。
- 地籍圖顯示中點空地或道路：顯示該點所在地號。
- 白模著色：建物中心落在某地號內即標示「地籍」（綠色）；資料庫匯入後所有建物幾乎都有地籍，因此顏色主要呈現「地籍」或「地籍＋實價登錄」。
- 地號的鄉鎮市歸屬由匯入時的 `--villages`（鄉鎮市界）依地號中心點判定；中心不在任何鄉鎮市界內者（離島等，67 筆）沒有鄉鎮市歸屬。
## 限制

- 地號面積是登記面積，不是建物面積；地籍資料不含所有權人，不可據此判定產權。
- 無段名對照表時只顯示段代碼；實價登錄的「段＋地號」尚未與此資料串接（需段代碼對照表）。
