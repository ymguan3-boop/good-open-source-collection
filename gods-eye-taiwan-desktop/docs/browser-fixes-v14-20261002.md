# 本機修改紀錄 v14（2026-10-02）

本次修改本機原始碼與已安裝工作區，未提交或推送 GitHub。

## 使用方式

| 功能 | 操作 |
| --- | --- |
| NLSC 建物 | 重新整理後載入建物。載入或再次顯示會啟用真實全球地形、關閉誇大的地形展示；Google 擬真 3D 底圖改為 NLSC 正射影像，避免兩套建物疊加。建物說明項下有展示高程微調。 |
| 對話儲存 | AI 空間助理 → 儲存對話；完成回覆後才可儲存。每筆使用台灣日期時間命名 MD。 |
| 紀錄查看與匯出 | 工具列「記錄」→ 點檔名查看，可拖曳右下角伸縮、按 × 關閉。匯出單筆為 MD；勾選多筆或匯出全部為 ZIP。可刪除不需保留的暫存。 |
| 自訂風格 | AI 空間助理 → 風格 → 輸入 → 儲存風格；從下一次回覆套用。清空欄位再儲存會恢復預設。 |
| 地圖標籤 | 標註與量測 → 地圖文字標籤 → 輸入文字、字體、顏色、字級與粗細 → 在地圖放置標籤 → 點地圖。每個標籤項下可修改。 |
| 多點路線 | 分析 → 行車路線與導航 → 起點、終點及任意中途點，可新增、刪除、上移及下移；選汽車或機車，再規劃路線。 |
| AI 查核行程 | 輸入起點、查核需求及停靠點；亦可查詢所在地學校候選名單。按 AI 建議 → 檢閱 → 套用建議 → 規劃路線；空白終點會於套用時填為起點，形成返回路線。 |
| CCTV AI 分析 | 分析 → CCTV → 圈選或一鍵觀看所有影像。選一般影像問答模型，在指定畫面按 AI 辨識車輛／車流。結果顯示影像取得時間，也加入 AI 對話，可儲存。 |
| 飛行資訊 | 圖資 → 飛機即時動態 → 點飛機，第一／第三人稱觀察卡同時顯示航空公司、機型、註冊編號、起訖機場、高度、速度、航向、位置及狀態。 |

## 實作與資料保存

- 建物保留官方 ECEF 座標及原始模型矩陣。沒有按相機位置猜測水平位移，也沒有把縣級包圍球高度當地面高度；細節誤差由 24 降為 8。展示高程微調預設為零，JSON 會保留展示設定，分析座標不變。
- 官方 20 公尺 DTM 載入的是可分析格網／樣點，不會自動取代 Cesium 地形表面。因此建物顯示另配合全球地形，並把高程誇大還原為 1。
- 自訂風格存於 `localStorage` 與 Dexie 的 `settings`，依時間選較新版本，寫入後讀回確認。一種儲存不可用時使用另一種；兩者都失敗時顯示中文錯誤。
- 對話 MD 存於 Dexie 新增的 `chatRecords`；保存的是當下對話快照，後續清除對話不會修改已儲存的紀錄。清除網站資料、無痕視窗結束或換瀏覽器設定檔，可能失去紀錄。請匯出保留。
- 資料庫升級保留原有專案、設定及舊 `results` 資料。舊成果 JSON 不會自動轉成對話 MD，亦不再列於新「記錄」面板；本次未刪除舊資料。
- 標籤保留 WGS84 點位與 `annotationLabel` 樣式，匯入／匯出 JSON 可還原。可選標楷體、新細明體、微軟正黑體與 IBM Plex Sans TC；作業系統未安裝時使用替代字體。
- 路線逐段向 TomTom 計算，串接幾何、距離、時間及轉向指示；AI 接收已解析的停靠點與起點座標，建議必須完整保留全部候選點，供使用者確認後套用。AI 排序不保證最短路線。
- 學校搜尋為 TomTom POI 候選名單，最多 100 筆，不代表宜蘭或其他縣市完整學校清冊。名稱、地址與範圍須檢閱，可自行增加或刪除。
- CCTV 模型清單按影像輸入與文字輸出能力篩選，排除安全分類、音樂及不保證交通分析的免費自動路由；需使用者選定模型才送影像。分類模型只回覆「safe」等文字時不會顯示為成功的交通分析。
- 每次 CCTV 分析只送所選影格與取得時間。數量與擁擠程度是模型推估，並非已驗證的偵測器；單張影像不能量測車速或每小時流量。來源離線仍逐路提示，不使用合成影像代替。
- 飛行資訊沿用來源追蹤資料，未知欄位顯示「來源未提供」，不自行補造航空公司、航班或機場。
- 本次僅同步修改檔案至 `.work/upstream`，未重新執行完整 overlay 套用。首次安裝腳本也已補上新舊工具列圖的複製，避免重新安裝缺少按鈕圖片。

- 影像模型清單、宜蘭學校搜尋回傳 HTTP 200；本輪學校查詢取得 12 筆候選，不當作完整學校清冊。
- 缺影像、缺行程需求回傳 HTTP 400 與中文提示。
- 汽車與機車路線實際 API 皆成功；本輪抽查短程均取得 64 個路線點、1874 公尺及 518 秒。只確認供應商路線可取得，不代表現地行車或導航鏡頭已驗收。
- 自訂風格五項邏輯檢查通過：一般保存／讀取、網站儲存不可用時使用資料庫、資料庫不可用時使用網站儲存、兩種都失敗時拒絕回報成功，以及固定時鐘下重載模組仍讀到較新設定。這些使用記憶體替身，並非實際瀏覽器重開的持久性驗收。
- 使用 `qwen/qwen3.8-27b:free` 實際分析國道 5 號官方影格，取得繁體中文車種、可見數量、不確定性及車流說明；未驗證模型計數的真實準確率。
- 免費模型實際回傳兩個指定停靠點的行程建議，後端核對點數及唯一性。此為少量候選與示範座標的 API 格式抽查，尚未執行宜蘭全縣學校完整行程。
- 首次抽查的 Gemma 免費模型發生供應商錯誤，改用另一免費模型後成功。可用性與免費額度依供應商；失敗可手動切換模型，程式不自動改用付費模型。
