# 宜蘭縣近 5 年綠地破碎化分析（2020–2024）

本分析使用 2020–2024 五個年度；Impact Observatory 10m Annual LULC 為年度變化主資料，OSM 補道路、河川與公園脈絡，NLSC 作為臺灣官方土地利用分類／可得性參考。

## 六項指標

- 綠地面積減少率
- 斑塊數增加率
- 平均斑塊面積下降率
- 道路＋建成區邊界切割壓力
- 孤立小斑塊比例（< 2 ha）
- 距大型連續同類綠地（>= 10 ha）

## 結果

- 有效類型－網格紀錄：5,006
- 高破碎化紀錄：1,674
- 運算解析度：30 m；篩選網格：1 km

## 限制與替代

- NLSC 國土利用 WFS 與歷年比較 API 為申請／綁定服務，本次年度變化改用免申請、可重現的 Impact Observatory 年度 LULC。
- 免費年度 LULC 完整資料目前至 2024，因此近五年採 2020、2021、2022、2023、2024 五個年度。
