主要發現

分析期間為 2023-09-25 至 2026-09-25。公開來源共解析 66 筆，其中 53 筆具備期間內日期與可計算空間幾何。依「50 公尺內至少 2 件施工」規則，共找到 2 處查核熱點；其中 0 處符合「前案完工後 180 天內再次施工」。

本成果是審計選案與查核篩選，不代表已認定浪費、違失或不當施工。

資料與方法

核心資料為宜蘭縣道路挖掘公開 XML，透過 ODPortal resourcedata 端點取得。資料包含案件、道路、日期、單位及 GML 施工多邊形／中心點；此次內容可見更新至 2026-09-24。

分析直接使用 EPSG:3826 施工幾何。任兩件施工距離 ≤50 公尺即建立空間關聯，連通群聚至少 2 件才列入。再檢查後案開工日是否落在前案完工後 0～180 天。道路名稱優先採官方 DG_ROAD / DG_ROAD2 欄位。

資料限制

  1. 66 筆公開 XML 不代表縣府內部近 3 年完整母體只有 66 筆。
  2. 工程類型部分依文字分類，正式查核應回查原始案件。
  3. 50 公尺表示幾何鄰近，不代表完全相同施工面。
  4. 2 個熱點都未命中 180 天短期再次施工。
  5. 違失或浪費仍需查閱施工必要性、契約、許可、整合施工與現場資料。

總結

目前公開資料共找到 2 處 50 公尺內重複施工空間群聚，0 處命中 180 天短期再次施工。RC-0001 因 5 件施工集中於相近範圍，較適合作為後續人工調卷的優先對象；RC-0002 則應先確認是否為同一工程、相鄰工區或同日整合施工。本成果定位為審計查核篩選工具，而非違失結論。
