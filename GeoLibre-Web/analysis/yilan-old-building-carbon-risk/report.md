# 宜蘭縣既有住宅碳排風險潛勢初篩分析

## 一、分析目的

本分析用於篩選宜蘭縣 12 鄉鎮市中，較值得優先進一步辦理建築能效、節能改善與碳排查核的區域。結果屬於**風險潛勢初篩**，不是個別建築的實際碳排量，也不是官方 BERS／BERSe 能效評分。

## 二、資料期別

- 鄉鎮市空間基線：2019 年底住宅屋齡結構。
- 宜蘭縣整體現況參考：2025 Q2，住宅平均屋齡約 35.0 年；30 年以上住宅 123,027 宅，占 60.5%。
- 後續建物級模型：優先檢視 1998 年以前建物，其中 1995 年以前標示為最高年代風險群。

## 三、初篩方法

綜合初篩指數 v0.2：

**65% ×「30 年以上住宅占比」min-max 正規化 + 35% ×「30 年以上住宅宅數」min-max 正規化**

分級：
- A 極高優先：75 分以上
- B 高優先：55–74.9 分
- C 中度：35–54.9 分
- D 較低：35 分以下

這個權重同時考慮「老屋比例」與「可改善住宅規模」，避免只看比例而忽略實際住宅數量。

### 主要發現

1. **蘇澳鎮**初篩指數 85.8，屬 A 極高優先；30 年以上住宅占比 71.28%，同時具有相當規模的老屋母體。
2. **頭城鎮**初篩指數 62.2，屬 B 高優先；老屋占比 63.17%，年代結構風險明顯。
3. **冬山鄉**雖落在 C 中度，但約 11,921 宅 30 年以上住宅，改善規模值得注意。
4. **宜蘭市、羅東鎮**老屋占比未居最高，但老屋絕對量大，因此在後續建物級節能改善評估仍具有重要性。
5. **南澳鄉、大同鄉**老屋比例較高但總量較小，適合以區域特性與建物用途進一步分層，而不宜只按比例排序。

## 五、限制與下一階段

目前模型只能回答「哪裡較值得優先進一步查核」，不能回答「哪棟建物實際排放多少碳」。

下一階段建議加入：
- 使用執照／建築完成日期
- 樓地板面積
- 建築用途
- 建築構造
- 樓層數
- 熱環境／都市熱島
- 空調、照明、熱水等設備條件
- 可取得時的實際用電資料

完成上述資料後，才能由鄉鎮級初篩升級為建物級「碳排與節能改善優先地圖」。
