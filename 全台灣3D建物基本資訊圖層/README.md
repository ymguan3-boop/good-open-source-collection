# 全台灣3D建物基本資訊圖層

本專案是《上帝之眼 台灣版》的獨立免費內建圖資候選層，不取代、不修改既有 NLSC 3D 建物圖層。

## 目標
建立可獨立載入、可3D拉伸、可查詢屬性、可追溯資料來源的全臺建物基本資訊圖層。

## 四階段架構
1. NLSC 3D 建物僅作空間比對/驗證參考，不複製其模型。
2. 整合政府公開建管資料：樓層、年份、用途、構造、面積、執照等。
3. FUNRAISE MCP 僅作補充來源；須先確認授權與快取/再散布條件。
4. 本機 SQLite/GeoPackage 快取，查詢時本機優先，缺值才呼叫外部來源。

## 資料可信度
- A：官方資料直接對應
- B：地址/地號/空間配對
- C：計算或推估值（必須明示，不得冒充官方資料）

## 目前狀態
v0.1 建立資料規格、來源登錄、GeoJSON 容器與 SQLite schema。尚未宣稱已完成全臺資料下載；後續逐來源驗證授權、可用性與覆蓋率後匯入。

## 匯入相容
輸出以 GeoJSON 為核心，保留可轉換成《上帝之眼 台灣版》既有 GeoLibre JSON 專案格式的欄位。3D 高度優先使用官方高度；無高度但有樓層時可產生「推估高度」，且 provenance 必須標記 derived。
