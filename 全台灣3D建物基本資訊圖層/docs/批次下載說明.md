# 批次下載及來源

來源：全國建管系統「建築執照存根基本資料」（BUILDLIC），官方文件 https://cpami.chcg.gov.tw/opendata/docs/a1.html

官方明訂單次最多100筆，Start=1、101、201……；本專案依官方分頁設計。

本程式採每頁至少3秒間隔（排程預設5秒）、429/5xx退避重試、每個篩選條件各自儲存 state.json 斷點與 SHA-256。每次最多50頁；GitHub Actions 每日臺灣時間02:00執行，亦可手動啟動。凌晨並非官方免限流時段。

**重要限制**：GitHub-hosted runner 每次是新環境。工作流程目前將原始下載結果暫存為7日 Actions artifact，**尚未實作跨次排程持久化**；因此自動排程每次仍從第一頁開始。需在核准個資處理與資料授權後，加入受控持久化儲存，才能真正跨日續傳。程式本身在同一持久資料夾下可斷點續傳。

**目前尚未驗證 API 實際可連線、回傳格式、空頁判斷及筆數；未將任何原始建管資料公開提交。** 使用執照資料可能含個資，需先做欄位白名單及去識別化，並驗證是否允許再散布。

NLSC 3D 圖層仍保持獨立；不得將執照筆數當成實際建物數。
