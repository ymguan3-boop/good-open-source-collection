# 官方資料來源與擷取紀錄（2026-10-09）

## 已確認文件、尚待實際取得資料
1. 全國建管系統「建築執照存根基本資料」：https://cpami.chcg.gov.tw/opendata/docs/a1.html
   - 官方欄位：地上/地下層數、建築高度、構造別、竣工日期、樓層用途、面積、地號及門牌。
   - API 規格：`OpenDataSearchUrl.do?d=OPENDATA&c=BUILDLIC&Start=1`，每頁最多100筆。
   - 查詢入口：https://building-apply.publicwork.ntpc.gov.tw/opendata/OpenDataSearch.jsp
   - **限制**：API 資料取得、批次利用條款、個資欄位過濾、全臺覆蓋率均待實測，不得宣稱已取得全臺建物。
2. 全國建管系統 GeoJSON 圖層文件：https://building-apply.publicwork.ntpc.gov.tw/opendata/docs/geo.html
   - 文件列有 BU（建築物）等圖層；需確認其實際幾何、座標與授權是否適合再發布。
3. 內政部國土測繪中心縣市界線：https://data.nat.gov.tw/dataset/7442
   - 免費、政府資料開放授權條款第1版；**僅行政區界，不能當作建物輪廓**。
