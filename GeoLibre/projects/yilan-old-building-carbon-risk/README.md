# 宜蘭縣既有住宅碳排風險潛勢初篩 v0.2

這是一份 GeoLibre 專案，用於篩選宜蘭縣既有住宅中值得優先進一步做能效/碳排查核的區域。

- 鄉鎮市空間基線：108 年底（2019）宜蘭縣住宅屋齡結構。
- 縣級現況參考：2025 Q2，平均屋齡 35.0 年；30 年以上住宅 123,027 宅，占 60.5%。
- 初篩指數：65% 老屋占比 + 35% 老屋絕對量（皆做 min-max 正規化）。
- **不是實際碳排量，也不是官方 BERS / BERSe 評分。**
- 最終建物級模型應以 1998 年以前為第一層重點，1995 年以前標為最高年代風險群，並加入面積、用途、構造、樓層、熱環境與實際用電資料。
