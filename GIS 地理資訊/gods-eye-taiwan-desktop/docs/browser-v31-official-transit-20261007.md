# v31 官方班表備援與 AI 功能說明重整（2026-10-07）

## 問題與修正

- TDX 成功取得權杖不代表每個路由都符合指定日期、中繼停留與期限。實際範例出現「候選出發時間不符」或逐段串接後超過期限；未觀察到此範例有 403／429，因此不能歸因於訂閱或額度。
- 原有臺鐵備援僅接受直接車站起訖，不能處理宜蘭縣政府及羅東停留。新增獨立官方班表來源與路廊服務；查無可靠方案或認證／權限／用量限制時自動使用公開來源，相同條件連續兩次失敗後停止重複 TDX 查詢。
- 「原因是？」「可以用爬蟲解決嗎」「?」直接進入運輸工作流程；點選及文字確認共用實際執行路徑。工作中以 SSE 回報各階段，結論自動送至 AI 空間助理，確認建議後顯示完整路線並播放 3D 行進示意。
- 查核原因保留 HTTP 狀態與實際條件排除數量。額度倒數仍只依官方資訊；沒有官方重置時間時不猜固定時刻。
- AI 工具列入口改為垂直的「AI語音助理說明」「AI空間助理說明」，保留各自的說明、風格、模型、連線與額度管理，使用不同配色。
- 修正重新啟動時已展開的運輸視窗沒有載入票種清單的問題；恢復視窗亦會查核清單，失敗時回報並允許重試。
- 官方備援時間統一為臺灣 +08:00，票價逐筆保留乘客票種與人數；重複查核不重複附加票價警示。完整估算預算與缺漏票價分開呈現。

## 官方來源及驗證

1. [臺鐵 ODS 每日班表清單](https://ods.railway.gov.tw/tra-ods-web/ods/download/dataResource/railway_schedule/JSON/list)：只接受清單內指定日期 JSON，不以其他日期冒充；驗證資料結構、班次類型、車種、站序與起訖時間。
2. [臺鐵 ODS 車站資料](https://ods.railway.gov.tw/tra-ods-web/ods/download/dataResource/0518b833e8964d53bfea3f7691aea0ee)：站碼、站名及官方座標。車種代碼依官方開發文件 V1.5；新代碼未核實時排除，不自行猜分類。
3. [NLSC 官方鐵路圖資](https://data.gov.tw/dataset/73220)：依官方班表停站順序串接隨附固定版圖資，不以站間直線冒充鐵路。模型行進為路廊示意，不代表實際營運股道或車輛即時位置。
4. 非車站起訖使用已設定的 TomTom 步行道路，驗證端點、座標及時間；沒有可驗證道路時不製造接駁線。
5. 費用由獨立 Fare Engine 查核官方票價服務。無確定價目時，依已爬取官方費率及量測里程估算，逐筆標示來源及依據；未核實學生優惠時以同段成人預算保守編列。估算不當成正式報價、不寫入正式票價快取。

公開來源採固定允許清單、robots 查核、禁止重新導向、不繞過登入或 CAPTCHA、請求節流、可設定 TTL、快取及重複請求合併。格式驗證失敗不以新資料覆蓋舊的有效紀錄。

## 實際驗收

- 2026-10-08 09:00 宜蘭縣政府出發，羅東車站停留至少 30 分鐘，13:00 前抵達臺北；成人、兒童及學生各 1 人，全部可搭。
- 真實官方資料產生 3 個候選方案；推薦步行接駁宜蘭站、區間車 4146 到羅東、10:55 自強 411 到臺北，12:25 抵達。保留日期、抵達期限、中繼點、停留及乘客限制。
- 瀏覽器點選「按你建議執行」自動回報結論並啟動 3D 示意；輸入「可以用爬蟲解決嗎」實際查官方公開來源並自動完成展示；原因追問有回覆。
- 範例三人的交通預算合計估算 NT$885，包含尚非正式報價的費用；正式已核實總價保留空值，實際營業里程與票種資格可能改變費用。
- 另以合成 TDX 429 額度回覆搭配真實官方公開資料驗證：仍取得宜蘭→羅東班次及完整路廊，沒有虛構額度重置時刻。此測試不表示使用者帳號真的額度已滿。
- 工作流程、票價、確認執行、路廊及官方備援測試共 67/67 通過；包含兩次失敗後停止重複查詢、保留配額原因、日期及 robots 驗證、車種限制、估算票種標籤與警示去重。

## 範圍與限制

新公開班表備援支援臺鐵直達班次的逐段組合與步行接駁，未窮舉全部運具、鐵路轉乘或全網最優解。公車、高鐵、捷運、輕軌及自行車仍使用既有 TDX／官方服務。官方尚未公開日期、不提供所選車種或無法核實接駁時，保留條件並明示問題，不自動放寬期限、改票種或產生虛構路線。

班表不保證即時延誤、餘票或實際營運股道；沒有可靠官方資料的條件無法保證成功。正式功能沒有測試替身、驗收掛鉤或合成 HTTP 錯誤。
