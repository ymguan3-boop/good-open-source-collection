## 建物計數方法與限制

1. 讀取目前載入的 NLSC 建物來源，找出官方同縣市「分棟／Individual」服務。
2. 依量測外框挑選候選 GLB 圖磚，讀取 `EXT_structural_metadata` 的 `BUILD_ID` 與 `CENT_E_97 / CENT_N_97`。
3. 中心座標由 EPSG:3826 轉為 WGS84；以 BUILD_ID 去重後計算中心點落在圓形／多邊形內的數量，另建立可顯示的建物中心成果圖層。
4. 統計與來源、方法、涵蓋及錯誤狀態一起傳給 AI，避免將 3D 模型視覺外觀當成沒有建物。

這是**建物中心點落入範圍**，不等於建物足跡相交；只代表官方模型版本的涵蓋，不是現況或法定清冊。為避免過量下載，單次限 2 平方公里、80 個葉圖磚、180MB。服務失效、缺少屬性、圖磚轉換不支援或預算不足會標示未知／部分結果，不將缺資料報為 0 棟。其他非 NLSC 的 3D Tiles 未必有可計數屬性，仍須使用建物向量或對應來源。

## 範圍與可用性限制

- 全台灣是一種查詢範圍，不代表每項來源均已完整下載內建。OSM 逐縣查詢有容量上限；此次公開服務請求逾時，未宣稱道路、水系、海岸線已通過完整全臺驗收。
- NLSC 全臺模式按視野切換縣市模型，全球影像及地形按視野串流。DTM 顯示可以抽樣，但量測直接讀本機官方 20m 格網。
- CCTV 為來源有提供的攝影機；飛機受公開來源涵蓋與可用性限制。AIS／FIRMS 需要對應金鑰，本次未配置可用憑證，未宣稱真實服務已驗收；圖資面板會提示所需服務。
- 縣市行政界採官方資料約 11 公尺簡化版作顯示及篩選。原始 ZIP 與完整 GeoJSON 保留於 `data/official/counties/`。線段與縣市相交時保留整段；海上及地震採縣市外框加 0.1 度周邊，非法律管轄界線。
- 載入的使用者專案保留原本範圍，不會被內建圖資範圍選項裁掉。即時資料仍須手動開啟；金鑰不寫入匯出的 JSON。
- 原版全球資料不全具有台灣縣市篩選語意；本次新增的台灣圖資來源由共用範圍控制管理。

## 來源與維護

- [NLSC 3D 地圖平台](https://3dmaps.nlsc.gov.tw/FrontMap/)：官方服務索引，分棟建物屬性。
- [縣市界線開放資料](https://data.gov.tw/dataset/7442)、[國土測繪中心下載服務](https://maps.nlsc.gov.tw/pro/download.jsp)：縣市篩選；原始來源 CRS 為 EPSG:3824，顯示使用 WGS84 經緯度，政府資料開放授權條款第 1 版。
- [TomTom Fuzzy Search](https://docs.tomtom.com/search-api/documentation/search-service/fuzzy-search)、[Traffic Flow raster](https://docs.tomtom.com/traffic-api/documentation/tomtom-maps/v1/traffic-flow/raster-flow-tiles)：本機代理搜尋、導航、真實交通。
- [Photon](https://github.com/komoot/photon)：沒有 TomTom 金鑰時的公開地點搜尋備援，合理使用且無 SLA。
- DTM 與鐵路版本、SHA-256、來源及限制沿用 `data/official/` 既有紀錄。
- 工具列素材：`branding/toolbar-bezel-v6.png`；提示詞摘要與整合方式：`branding/toolbar-bezel-v6-prompt.md`。
- 可重建來源在 `overlay/` 與 `scripts/apply-overlay.mjs`；本機實際執行來源在 `.work/upstream/`。不要在仍有未整理修改的 checkout 上重新套用 overlay。
