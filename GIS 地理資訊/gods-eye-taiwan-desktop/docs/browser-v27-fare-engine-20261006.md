# v27 官方票價引擎與乘車偏好（2026-10-06）

## 目前狀態

本機瀏覽器預覽已加入獨立票價服務、共享偏好與官方來源更新機制；此次變更同步至 GitHub 原始碼，未宣稱全部端到端驗收完成。官方資料只涵蓋實際已核實的路線，未取得資料明確標為未知，不宣稱全臺所有票價正常。

## 使用方式（最少點擊）

1. 工具列「分析」→「AI智慧大眾運輸」。
2. 藍色「表單輸入」填起訖／時間，或紫色「AI自然語言」描述需求。
3. 預設成人全票 1 人、臺鐵全部可搭；有特別需求再展開「乘車與票價偏好」。
4. 僅按「依最新交通資訊進行AI規劃」。完整需求直接查詢，只有同名地點或缺漏才要求選擇／補充。結果進 AI 空間助理，推薦旅程自動在同一地圖顯示。
5. 多選高鐵車廂即可比較正式報價；同路線不同實際班次的金額與時間差由程式計算，AI只解釋數字。

臺鐵選項來自 TDX TrainType 目前實際清單，官方細分 ID 保留，重複名稱合併顯示。只有展開限制列車時才顯示這些選項；沒有價格差別的公車、捷運、輕軌不增加車型／座艙選項。臺鐵特殊座艙只對已核實支援的車種顯示，不由名稱偶然出現的「3000」推定。

自然語言範例：

- 「我只想搭區間車去台北。」
- 「台鐵可以搭自強，但不要比較貴的特殊座艙。」
- 「高鐵只幫我算自由座。」
- 「幫我比較高鐵自由座和標準車廂。」
- 「我們有2個大人和1個小孩。」
- 「不限定車種，幫我找最便宜的。」

「我只想搭區間車去台北」可直接更新明確目的地並保留已有起點／時間；起點未填時只詢問起點。複雜時序或途經條件仍需外部免費模型成功理解，不能假稱已解析。

模型回傳的金額／來源網址不是合法需求欄位；未提及的乘客或車廂不被模型補出的預設覆蓋。需求先轉為 TripPlanningRequest／FarePreference，再查官方班次與票價。

## 維護架構

```text
表單 / 自然語言
      ↓
共享 TripPlanningRequest + FarePreference
      ↓
實際候選班次、車種與車廂限制
      ↓
FareService（TRA / HSR / BUS / METRO / LRT / BIKE）
      ├─ TDX / 官方 API
      ├─ 官方公開網頁 adapter
      └─ 已驗證 FareCache
      ↓
各 TripSegment FareQuote / 混合乘客總額
      ↓
確定性費用與時間比較 / 推薦排序
      ↓
AI 空間助理 / 原 Cesium 3D 旅程資訊卡
```

原始碼：

- `overlay/src/taiwan/farePreference.js`：共享型別、人數、車種／車廂／票證規則與官方車種分組。
- `overlay/server/providers/fareEngine.js`：各運具票價 adapter、乘客／車廂計算、候選推薦與比較。
- `overlay/server/providers/fareCache.js`：本機版本化已驗證報價、TTL、來源 hash、解析版本與異常跳價隔離。
- `overlay/server/providers/officialFareSources.js`：固定官方來源與 robots／Crawl-delay／origin 排程。
- `overlay/server/providers/fareWebAdapters.js`、`tdxFareWeb.js`：高鐵、YouBike、臺鐵、臺北捷運公開表格解析。
- `tdxService.js`、`tdxGeometry.js`：實際班次／站點／公車計費緩衝區／自行車系統核對。
- `transitPanel.js`、`providerSettings.js`、`journeyDisplay.js`、`ui.js`：動態偏好、資料更新狀態、3D 資訊卡及助理結果。

## 官方來源與計價範圍

| 運具 | 計算依據 | 網頁備援 / 限制 |
| --- | --- | --- |
| 臺鐵 | 同日、同 OD、同時刻的實際班次／車種，再查相符票種與座位 | [官方票價試算](https://www.railway.gov.tw/tra-tip-web/tip/tip001/tip114/query)；最短營業里程可能與實際車次行駛不同，最後依票面 |
| 高鐵 | 官方 OD 的 TicketType／FareClass／CabinClass | [一般票價](https://en.thsrc.com.tw/ArticleContent/4c3efc1d-e6df-4bfd-97b4-52e89f79ee5c)、[自由座](https://en.thsrc.com.tw/ArticleContent/4db23462-3589-4f0e-8158-29f5ccfe3117)；不推定庫存、早鳥或資格 |
| 公車 | 實際業者、路線、子路線、方向、站點／站序；官方 OD／區間／分段規則 | 多段票需官方緩衝區與站序可唯一核對；不以車型或公里數猜價格，複雜未核實規則未知 |
| 捷運／輕軌 | 營運系統、起訖站、官方票種／票證資料 | 臺北捷運可補查[官方 OD 票價](https://web.metro.taipei/pages2026/WebStation/051/8)；站內換線按完整 OD 計一次，不分段重複收費 |
| 公共自行車 | 兩站已核實系統／地區、規劃租借時間、官方基本計費級距 | [YouBike 官方費率（臺北範例）](https://www.youbike.com.tw/region/taipei/rate/)；無會員／地方補助假設，最後按實際還車時間 |
| 步行 | 免票 | NT$0，不需要爬票價 |

票種資格仍以運輸業者規定及現場驗證為準。官方票價與班次資料不代表可訂票或保證座位；不把條件未核實的優惠計入結果。所有網頁只有事先設定的官方來源，公開讀取，不繞過登入、CAPTCHA、反爬機制；目前 YouBike 的 Crawl-delay 5 秒已遵守。

## 快取、更新與容錯

- 已驗證公開票價保存在 `%LOCALAPPDATA%/GodsEyeTaiwan/fare-cache.json`；不含金鑰、Cookie、HTML、自然語言原文或使用者地圖座標。
- 每個報價保存 sourceUrl、fetchedAt、sourceUpdatedAt、effectiveFrom（官方有提供時）、contentHash、parserVersion 及必要來源定位。
- 預設 TTL 24 小時；可在既有 TDX 設定區調整（1 分鐘～30 天），不需要重輸 Key。
- 啟動只背景重新驗證過期的已使用來源；一般規劃先讀最新已驗證快取。手動「更新最新票價」更新官方選項與已使用報價，不爬完整所有網站。
- schema、有限非負金額、起訖／車種／車廂／票種、來源 allowlist、日期與異常價格跳動驗證先於覆蓋。
- 生效日期依乘車日期驗證，未生效或已失效的票價不套用於旅程；臺鐵生效日期由官方票價計算原則解析，沒有標示就留空。
- 非法日曆日期（如2月30日）會被拒絕，不接受JavaScript自動轉成3月。
- 新價格比前值改變超過50%且差額超過 NT$10，先隔離、提示重新驗證，不覆蓋舊值；此門檻屬檢查策略，不代表官方允許的調價範圍。
- 網頁改版、來源錯誤、非唯一金額或日期未生效時保留舊報價／日期並明示「最近一次成功驗證」。沒有舊資料就保持未知；不把搜尋摘要或模型知識當票價。
- 設定狀態依已核實筆數呈現部分／無資料與最後時間；只有已證明完整來源才有資格宣稱全網正常，目前未宣稱。

## 待續驗收與資料限制

- 七運具的完整真實旅程、跨城轉乘、各業者複雜公車段數與自行車完整費用，以及長時間播放／資源壓力。
