# v37 缺口彙整、可執行追蹤與 DTM 安裝（2026-10-08）

## 本次修改

- 圖資分析的逐網格錯誤保留於本機診斷，畫面與模型輸入改以建物完整性、額度、權限、連線、幾何、來源及涵蓋分類。只數字不同的相似錯誤合併，不把圖磚數加總為建物數。
- 紀錄索引更新至版本2，重新建立一次摘要；歷史原文及來源指紋保留。摘要中的重複建物缺口先壓縮，跨紀錄再分類彙整；歷史缺口標明摘錄而非重新查核。
- 三項追蹤選項在批次成果完成後產生，依實際圖資、已計算數量、紀錄專案／地點、事件及使用者查核重點選擇。模型只解讀摘要，不能另外提出未註冊的承諾。
- 點擊選項直接整理同一份成果快照的比較、來源、證據或缺口，無須再查外部服務或再呼叫模型，回報完成階段與結果，不再提出一輪建議。資料不足顯示未知或部分涵蓋；不假造缺少的成果。
- 初始分析取消或失敗時不附上無法執行的追蹤按鈕；v36確認後直接交付與重複確認保護保留。

## DTM 原因與修正

GitHub與發布包排除269MB ZIP及757MB原始GeoTIFF，舊首次安裝未下載。原 provider 也依固定相對層數找檔，在直接 Overlay／不同深度工作區會找錯位置。

- Windows 首次安裝完成程式建置後預設呼叫官方下載腳本；`--skip-dtm` 可略過。
- 既有安裝以 `npm.cmd run install:dtm` 補裝／續傳，不需 Agent 或 API Key。下載失敗明確回報，程式安裝仍保留。
- 依專案標記定位原始檔；提供本機 `/api/taiwan/dtm-2025/status`，缺檔錯誤附補裝指令。
- 使用串流 SHA-256，避免 PowerShell 模組差異；有效原始檔沿用、不重複下載。不符雜湊保留原檔停止，不自動覆蓋。
- 來源、容量、指令、雜湊與故障排除已寫入 README。原始DTM不提交GitHub。
