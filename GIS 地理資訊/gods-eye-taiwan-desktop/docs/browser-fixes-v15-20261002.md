# v15 修改與驗收紀錄（2026-10-02）

## 需求與修正

### NLSC 3D 建物缺漏

- 前次在準備建物表面時開啟全球地形深度遮蔽。官方建物與全球地形高程不同時，較低建物會被地形蓋住。
- 抽查官方宜蘭縣 tileset：3D Tiles 1.1，73,666 個階層節點／內容。抽查葉圖磚在北緯 24.7454847965、東經 121.7205243618，包圍球中心橢球高約 39.690 公尺、半徑約 11.178 公尺；同點 Cesium World Terrain 高程約 55.522 公尺。這是遮蔽原因的樣本證據，不能由此推論全縣固定高程差。
- 可見 NLSC 建物時停用地形深度遮蔽；最後一個建物圖層隱藏／移除後還原原設定。不修改官方水平座標或模型高度，不套用依鏡頭推算的偏移量。
- 保留屏幕誤差 8 像素，停用動態／周邊視野的誤差放寬、移動時的請求裁減及跳層，以提高可見建物細節完整性；快取預算維持 256 MB、額外上限 128 MB。
- 「說明與分析」新增即時下載／處理／已載入／失敗圖磚進度；保留高程微調。圖磚數不是建物棟數，載入完成僅指當前視野。
- 真實瀏覽器載入宜蘭官方模型並放大、平移街區，看到密集低樓層建物，進度曾顯示 275 個圖磚、零下載與處理、視野完成。未對全臺每棟建物逐一核對；來源未建檔、更新年代或本身缺漏不會由程式自動補出。
- 深度遮蔽停用後，地形也不會遮住位於山後的建物；這是展示完整性取捨，不適用於判斷視線遮蔽或精密高程。

### CCTV 自動免費模型

- 預設自動選擇；每分鐘刷新 OpenRouter 模型目錄，僅保留可輸入影像、輸出文字、輸入／輸出及圖片／請求價格為零的模型，排除安全分類模型。
- 可指定優先免費模型；失敗仍替換其他免費模型，付費模型無法指定。
- 所有 CCTV 分析依序執行，避免同時大量送出造成限流；429 冷卻 60 秒、其他失敗 30 秒。單一模型最多等 35 秒，每次分析整體最多 120 秒；關閉總覽可取消排隊或進行中的請求。
- 每次請求加入供應商 prompt／completion／image／request 價格上限零。免費額度與服務可用性仍由 OpenRouter 與供應商決定；全部失敗時顯示可理解的繁體中文訊息。
- 結果顯示實際免費模型、替換次數與影像時間，並加入對話；單張影像判讀無法提供實測車速或連續車流量。

- 實際總覽分析發現原有 Unix 毫秒時間在 DOM 中轉為字串，導致 Invalid Date；已統一轉為 ISO 時間，後端亦兼容毫秒字串。

### 記錄圖示與按鈕

- 新圖檔原本被更高優先序的舊 sprite 樣式覆蓋。提高記錄按鈕選擇器優先序，實際採用 toolbar-record-sheet-v10.png。
- 儲存對話加入清除／風格共用樣式：12 px 字級、5 px 內距、1 px 邊框、5 px 圓角。

## 驗收結果

- Vite 正式建置成功：1,193 個模組，33.35 秒（修正影像時間後重建）；現有 chunk 大小與 Tauri import 警告仍保留。
- 實際瀏覽器確認記錄圖示文字，以及三個對話按鈕一致的計算樣式。
- 真實宜蘭建物載入、視野放大與平移、圖磚完成狀態確認。
- 模型替換的隔離檢查：429 → 502 → 第三免費模型成功；最大同時請求 1、付費請求 0，取消後不送出新請求，付費模型指定遭拒。
- 本機 API 查得 8 個免費影像模型、預設 auto-free；實際官方 CCTV JPEG 分析 HTTP 200，自動替換 4 次後使用 dots-studio/dots-3-note-preview:free，取得 423 字中文判讀。
- CCTV 總覽介面確認 1,855 支目錄、每頁 12 路連續播放及預設自動免費模型選項。
- 前端檔案已同步至本機 .work/upstream 並建置；後端已同步並重啟。未重新驗收 Tauri 原生 EXE、麥克風或所有第三方服務。
