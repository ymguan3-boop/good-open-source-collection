# v36 確認建議後直接交付成果

日期：2026-10-08。

## 修正範圍

- 全面搜尋 AI 介面與確認處理入口；實際「按你建議執行」按鈕由大眾運輸流程產生。統一按鈕與文字確認的判定。
- 已確認執行後不再進入三項修正建議分支；直接回報規劃表格、票價來源與地圖展示狀態，或實際未完成原因。
- 過期／已出發方案保留限制自動重查官方班次一次；同一方案的地圖準備失敗最多重試一次。不無限重查、不擅自放寬條件。
- 查無官方方案、權限錯誤與展示失敗都有終態回報，分別區分未完成、部分完成及完成；不以文字回覆冒充路線或3D展示。
- 專案圖資及紀錄的建議接續分析直接回報成果、來源表格與缺口，移除新一輪查核建議及選項。已採用的舊建議停用。
- 再次確認同一項已完成工作直接顯示既有成果，不重複運算或呼叫模型。分析中確認仍維持背景批次工作，最後只回報成果。
- 通用文字建議若沒有已登錄的分析來源或可執行方案，直接回報缺少執行內容，不由文字模型宣稱已執行。

## 檢查與限制

- 隔離頁使用實際前端控制器，合成交通 API 與地圖替身，共52項檢查通過：成功、查無班次、權限錯誤、過期重查、重查仍過期、展示失敗、展示重試成功、缺少起點後補充仍接續執行、重複確認與成果格式。
- 正式瀏覽器紀錄分析已確認：點擊建議及文字確認後回報來源／摘要表格，最新結果不含新建議標題或接續按鈕。模型回覆不符合成果格式時保留本機摘要與來源，不猜統計。
- 真實本機交通服務抽查臺北車站至京站、僅步行：服務回報目前不支援此模式；按確認後直接回報實際未完成原因，最新規劃結論無建議按鈕。此案例未取得路線，不宣稱3D驗收成功。
- 最終正式介面已確認：分析中可輸入確認；最後只有來源與摘要表格、無新建議標題或按鈕，重複確認顯示既有成果且無新工作階段。
- 正式Vite建置成功；既有大型bundle警告仍存在。
- 合成檢查只驗證流程，不代表真實TDX、所有資料來源或實體麥克風驗收。
- 不能保證外部服務永遠可用或任何條件都有可行路線；缺少起終點、資料不足或服務失敗時如實回報，不能假造班次、金額或完成狀態。
