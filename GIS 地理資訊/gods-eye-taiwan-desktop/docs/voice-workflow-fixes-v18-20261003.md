# v18 語音圖資與地點操作修正（2026-10-03）

## 本次修正

1. 接續原圖資與操作，接受「全台灣」「那就宜蘭吧」及可唯一判定的縣市簡稱；禮貌問句仍視為操作要求。完整圖資＋區域不重問已提供的資訊。
2. 完成結果不再以使用者訊息送回模型啟動新回合，改由程式直接顯示並使用中文語音合成播報實際結果。完成後等待新指令，未停止整個語音連線。
3. 保留執行中回合，避免模型工具晚到時遺失完成回報；逐字稿與工具不同順序仍可接續。依操作去重，停止與取消保留原控制方式。
4. 重新指定已載入圖資的區域，會比較該圖層的實際資料範圍並重載；即時來源重新套用區域篩選。「載入」仍使用固定版，只有明確「更新」才查詢線上向量。
5. 「帶我到／帶我去某地」使用既有搜尋及相機工具，新建獨立標籤圖層；沿用標註清單、樣式、拖曳、移除與JSON專案保存，不建立第二個地圖。

來源只有全球／全臺或沒有縣市服務時，仍說明限制與建議。兩分鐘待補期限、繁簡字、有限同音誤字對照保留；新竹／嘉義未區分縣市時不猜選，多個不同範圍不擅自選一個。

## 使用方式

重新整理程式並重新開啟語音助理。

- 直接說：「能不能幫我載入宜蘭道路中心線」。
- 或說：「載入道路中心線」，被問範圍後說「全台灣」「那就宜蘭吧」或「新北市」。
- 定位說：「帶我到宜蘭縣審計室」或「帶我去台北101」。
- 完成後只回報實際結果，等待使用者下一個新指令。沒有可用中文合成語音時仍保留文字結果；一般對話仍使用Gemini Live。

## 驗收限制

未使用使用者實體麥克風、目前Chrome設定檔或Tauri桌面視窗抽測；未重新打包EXE。地點搜尋結果依既有TomTom／備援來源，不代表地籍定位。未宣稱每項圖資的所有街區或外島皆經視覺抽查。免費服務額度與來源可用性仍依供應商實際回覆。
