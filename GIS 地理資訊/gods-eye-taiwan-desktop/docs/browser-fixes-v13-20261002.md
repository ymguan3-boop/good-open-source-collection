## 操作位置

| 需求 | 使用方式 |
| --- | --- |
| 行政區界樣式 | 圖資 → 行政區界 → 縣市界／鄉鎮市區界 → 說明與分析，調整框線顏色、1～8 像素粗細（每次 0.5 像素）及顯示框線。專案內亦使用同一組控制。 |
| 單一專案／工作區收合 | 專案面板第一層名稱前的箭頭，可收合所有子圖層及專案分析。顯示切換與刪除按鈕各自獨立。 |
| JSON 圖資收合 | 圖資面板的 JSON 專案名稱列可收合；含匯入的內建圖層、影像服務及一般向量。收合狀態保存在目前瀏覽器，切換面板仍保留。 |
| 參考圖直接載入分析圖層 | 圖資 → 全臺參考圖 → 說明與分析，提供道路中心線、河川／水系中心線、水域面、鐵路四個載入按鈕，沿用目前範圍。 |
| 台灣地形地貌 | 圖資 → 全球地形 → 台灣 3D 地形地貌，預設將地表高程視覺放大 3 倍，可改為 1～6 倍，含正射影像、固定坡面光源及青色縣市界。 |
| NLSC 底圖 | 圖資 → 影像與擬真底圖，新增 NLSC 臺灣通用正射影像及臺灣通用電子地圖。 |

## 實作重點

- 樣式控制呼叫既有 `updateLayerStyle`；行政區面透明填色，框線使用貼地折線，可實際調整粗細，JSON 匯出沿用樣式欄位。
- 收合只是隱藏清單項目，不改變地圖上的圖層顯示狀態。
- 參考圖使用 EMAP2 WMS，非分析向量。道路／水文載入隨附 OSM 固定版，鐵路載入官方開放資料，來源在介面明示。
- 新底圖使用官方 WMTS 的 `PHOTO2`、`EMAP` 與 `GoogleMapsCompatible` 矩陣，最高層級 19；圖磚列與欄順序為 `{TileRow}/{TileCol}`。涵蓋來源提供的台灣及外島範圍，保留國土測繪中心來源標示。
- 地形展示沿用已載入全球地形；否則依已存金鑰讀取 Cesium World Terrain，未有金鑰時讀取 Re:Earth／Mapterhorn。沒有使用 AI 生成高程。
- 展示期間暫時隱藏原底圖及 3D 建物；隱藏或移除展示後恢復原狀，切換其他底圖則自動退出展示。高程倍率不修改資料、不取代官方 20 公尺 DTM，也不因展示而新增一套 globe viewer。
- 只同步修改檔案至 `.work/upstream`，沒有對現有工作區重複執行完整 overlay 套用。

## 同回合追加：TomTom 點位偏離路面

使用者提供傾斜 3D 畫面，移動點位與道路錯位。程式的車流細線已使用 `GroundPolylinePrimitive` 貼合地形與 3D Tiles，但圓點使用 `PointPrimitive` 搭配 `globe.getHeight`，只能取得地形高度，並以 `disableDepthTestDistance: Infinity` 強制蓋到畫面上。Google 擬真 3D 路面與該高度不同時，會產生視角偏移。

修改 `trafficDots.js`，移除獨立高度點位，使用同一道路幾何的 `GroundPolylinePrimitive`、`ClassificationType.BOTH` 與圓點動畫材質：

- 點位與既有細線使用完全相同的道路座標，讓 Cesium 直接投影到地形／3D 表面，不再用零高程或地形高度猜路面。
- 既有車流細線寬度維持 1.3 像素，封路線維持 2 像素，封路沒有移動點位。
- 動態圓點寬度 4 像素，最多取 800 條路段；速度依路況比例與路段長度分組。相近速度以 sqrt(2) 級距合併，為控制繪圖量的示意速度（約 19% 內的分組近似），不是逐車定位。
- 不逐頂點或逐畫面讀取 GPU 高度，避免先前密集道路時卡住；隱藏／移除仍停止動畫及釋放資源。
- [Cesium 貼地折線官方文件](https://cesium.com/learn/cesiumjs/ref-doc/GroundPolylinePrimitive.html) 說明此方法支援地形與 3D Tiles；自訂材質沿路段紋理座標移動。
- 需重新整理目前視窗載入新程式，再載入／更新 TomTom，才能移除舊程式產生的浮動圓點。
- 語法及正式建置已通過；本回合 computer-use 已被停止，因此點位貼面與動畫材質尚未完成實際畫面驗收。

## 同回合追加：飛機視角與語音圖資

- 新增 `flightObservation.js`：點選原版飛機追蹤目標後，顯示第一人稱、第三人稱、停止觀察卡。第一人稱經原版 `setContextMode` 與 `controlCockpit` 入口；第三人稱重新取得原版追蹤鏡頭。沿用既有鏡頭更新，不另外建立一套飛機動畫／鏡頭迴圈。
- 機號、航向與位置沿用來源資料；位置延遲時顯示推估提示。切換期間可中止，失敗還原先前模式；停止觀察還原由此功能自動開啟的飛機模式。
- 新增 `layerVoiceActions.js`：白名單圖資清單、指定載入／顯示／隱藏／切換／更新、一鍵載入內建圖資、一鍵隱藏。名稱不明確時回報候選項目，不猜測要操作的圖層。
- `geminiLive.js` 加入宣告、順序執行及工具取消處理；語音中斷連線會取消尚未完成的圖資載入。工具結果核對實際顯示狀態，回報逐項成功、失敗及部分資料，不只回傳已收到命令。
- 語音一鍵隱藏保留 Gemini Live 連線，關閉即時更新與其他工作，Google 擬真 3D 底圖維持既有選擇。必需金鑰檢查沿用工具列設定。
- 一鍵載入涵蓋目前範圍全部內建向量、官方 DTM、NLSC 建物、全臺參考圖，與工具列按鈕一致；即時串流與底圖以指定圖資命令操作。
- `ui.js` 沿用既有載入函式，補上外部取消訊號、嚴格錯誤回報及語音保持連線選項。既有手動按鈕仍使用同一載入路徑。
- 新增語音示例及觀察卡樣式；重新整理程式並重新啟動 Gemini Live 後，新的工具宣告才會加入連線。
- 依 [Gemini Live 工具呼叫官方文件](https://ai.google.dev/gemini-api/docs/live-api/tools) 使用 session function declarations 及 function responses；沒有交由模型任意執行 JavaScript 或操作 DOM。
- 語法與正式建置通過。因本輪 computer-use 已停止，尚未確認飛機點選與第一／第三人稱實際視角，也未做真實麥克風語音端到端驗收。
