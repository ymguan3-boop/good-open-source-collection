# v30 運輸助理執行回報與官方來源（2026-10-06）

## 問題與修正

建議按鈕先清除了待確認狀態，但未鎖住對話，背景查詢時送出的訊息落入一般空間文字模型。該模型沒有執行 TDX 的能力，將空間圖層為零誤解成沒有串接資料服務。「按你建議」也未被舊確認規則辨識。新增 transitAssistant 共用訊息路由與 runTransitInteraction：按鈕及文字確認都等待同一項實際工作，執行期間禁止重複送出，完成與失敗均直接回報。

資料工作流程：使用者確認 → 保留旅程與票種條件 → 真實 TDX 查詢 → 伺服器保留方案與 Fare Engine 查核 → 自動規劃結論 → 3D 展示。結論先於 Cesium 載入回報；地圖準備失敗不隱藏已查核班次及費用。查無方案時立即顯示原因及三個建議，其中包含「按你建議執行」。不以無限請求保證外部服務成功。

## 限制與倒數

新增 tdxLimits 保留 HTTP 狀態、官方 Retry-After 與重置資訊，經 middleware 傳至瀏覽器；本機冷卻期間不重複打同一來源。分類區分查詢頻率、官方明示用量額度、權限及驗證錯誤。TDX 已設定與有有效權杖分開顯示，不以圖層數判斷串接。

- 官方有額度重置時間：顯示「官方額度恢復倒數」。
- 僅有 Retry-After：顯示「官方允許重試倒數」；不宣稱帳號額度已恢復。
- 沒有官方時間：本機採 60 秒退避，明示這不是額度恢復時間。
- 每秒更新畫面倒數，不發送 API 請求，不猜每日固定恢復時間。

參考 [HTTP 429／Retry-After](https://developer.mozilla.org/zh-TW/docs/Web/HTTP/Reference/Status/429) 與 [TDX 官方平台](https://tdx.transportdata.tw/)。不同訂閱與端點限制仍依實際官方回應，不能從通用會員方案推算特定帳號剩餘量。

## 官方票價擷取

「請爬蟲查核官方票價來源」會實際呼叫 official-fare-info，透過既有 Fare Engine 官方來源清單、公開頁面、robots、請求間隔與快取控制，回報網址、擷取時間、內容雜湊及結果。不是把網頁文字當作正式金額；起訖、車種、車廂、票種仍需計價驗證。未知票價與有依據估算沿用 v29 規則，不能由文字模型自行計價。

本次通用來源查核支援：

- [臺鐵官方公開票價查詢與計算原則](https://www.railway.gov.tw/tra-tip-web/tip/tip001/tip114/query)
- [高鐵官方公開票價表](https://en.thsrc.com.tw/ArticleContent/4c3efc1d-e6df-4bfd-97b4-52e89f79ee5c)

其他運具依實際業者／路線的既有官方 adapter 查價；不宣稱已建置所有營運業者爬蟲，亦不任意抓非官方網址。

## 驗收

- 新增工作流程 11/11：確認同路由、追問不落入文字模型、官方／本機倒數、真實 HTTP fixture 冷卻、過期日期確認、併發防重、地圖失敗仍回報、結論先於地圖準備及真實 allowlist fetch，確認執行失敗後重新提出可操作建議，以及不攔截 Gemini／OpenRouter 額度或非運輸官方 GIS 查詢。
- 旅程執行回歸 16/16；票價 29/29。既有運輸後端本批次前段 44/44；不是完整 upstream 回歸。
- Vite 正式建置通過（1233 modules）；模組邊界檢查通過。
- 實際本機 API 的 status 回報 configured=true；official-fare-info HTTP 200，取得上述兩個官方公開頁面與時間，未顯示金鑰。
- 實際瀏覽器過期日期提出三點建議；按鈕確認觸發查詢，遇到真實 TDX 頻率限制後自動提出新建議及官方允許重試倒數，沒有要求手動載入圖層。
- 等待官方允許重試後，直接回覆「按你建議」：自動回報 2026-10-07 宜蘭→羅東 410 次官方班表（09:13–09:19），成人一人估算 NT$34，標示臺鐵官方費率、8.90 公里線型量測與最低 10 公里計價依據。自動開始 3D 行進示意，剩餘距離實際遞減，展示停止可操作。全程未再詢問「好了嗎」。
- 最後建置修正候選查詢完成後建議按鈕未解鎖、靜態錯誤說明重複倒數與過時進度；正式畫面只由動態節點更新倒數。最終建置實測候選方案按鈕正常解鎖，點選「按你建議執行」直接輸出結論、播放並完成模型行進示意；模型與展示視窗均可見。

官方直達班表備援不代表窮舉所有運具；估算不是正式票價或購票保證。外部資料仍可能因頻率、訂閱、認證或無班次而無法完成；必須如實回報原因，不以空白或純「執行中」代替結果。既有語音、空拍與 CCTV 未在本批次重做完整驗收。

真實回應與截圖僅保留本機 logs/qa-v30，發布不含金鑰、快取、日誌或測試掛鉤。
