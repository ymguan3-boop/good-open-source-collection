# v32 視窗、額度與空拍控制（2026-10-07）

## 變更

- AI 返回入口統一顯示「返回」，深色底搭配淺色字。AI 空間助理說明移除大眾運輸捷徑；分析工具中的原入口保留。
- 所有共用浮動視窗與既有視窗標題列統一三個圖示：縮小／展開、功能及說明、關閉。縮小持續背景工作；關閉沿用各功能的停止及資源釋放流程。
- 操作說明、提問範例、操作範例及規劃安全說明集中至可關閉的獨立說明視窗，使用條列排版。互動表單、圖層資料與分析結果保留原操作。
- 移除語音及空間助理的額度檢查按鈕，進入頁面自動讀取；頁面可見時每 60 秒更新。
- 空間助理優先顯示 OpenRouter API 回傳的免費模型每日請求上限及剩餘次數；未回傳時才使用金鑰金額上限。無可計算上限時顯示未知比例，不以已用 0 美元推定免費額度無限。
- Gemini 使用同款額度卡及未知狀態血條；未提供精確比例及重置時間時明示，並保留 Google AI Studio 連結。不讀取使用者帳號或假造用量。
- 地圖文字標籤改為與路徑、多邊形等一致的按鈕與色票。點擊進入原有文字、字體、字級、粗細及顏色設定，支援返回。
- 拍攝中正上方新增「加速拍攝」：正常 1 倍、1.5、2、2.5、3 倍。手繪模式調整沿軌跡的速度及加減速；自由模式調整平移與升降速度，前方檢查範圍隨速度調整。
- 自由空拍第一人稱右上角顯示 W／S、A／D、I／K、J／L、滑鼠與 Esc 操作說明。切換倍率後焦點回到地圖，鍵盤仍可操控。
- 加速選單及操作 HUD 均為 DOM 覆蓋層；錄影器僅擷取 Cesium 畫布，控制介面不進入影片。各倍率仍保留連續路段及障礙驗證，未知時不放行。

## 實際檢查

- 正式 Vite 建置完成。
- 瀏覽器檢查「返回」的計算樣式為深藍背景及淺色字；縮小與展開使用同一控制按鈕，說明視窗可獨立關閉。
- OpenRouter 真實回傳免費模型每日上限 50、剩餘 50、已用 0，顯示剩餘 100%。此為檢查當時數值，後續以 API 回傳為準。
- Gemini 額度顯示「未提供比例」，保留官方查詢連結；未為此檢查啟動麥克風。
- 語音功能／提問／畫面操作範例、空間功能設計及空拍操作說明均可由標題列「?」開啟。
- 文字標籤按鈕與其他繪製工具格式一致，原有樣式輸入可開啟及返回。
- 在實際 Google 3D 圖磚場景完成自由空拍錄影，確認右上角操控說明、加速選單及 3 倍選取；Esc 停止後產生影片預覽並保存至記錄。
- 手繪速度倍率已接入實際路徑運算並通過正式建置，本批未另完成手繪軌跡實拍或逐倍率定量速度比較。
- 本批未新增或執行自動測試；未變更交通 API、票價引擎或語音連線流程。

## 額度來源

- [OpenRouter current API key](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-api-key)：免費每日請求欄位、金額限制及用量資料。
- [Gemini API rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)：依專案及方案的實際限制，以 Google AI Studio 為官方查看入口。

API 未回傳下次確切重置時間時，不以 ChatGPT 範例圖的週額度日期替代。正式發布只包含來源與文件；本機影片、截圖、金鑰、快取及建置輸出不提交。
