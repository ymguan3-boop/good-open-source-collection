# 宜蘭縣既有住宅碳排風險潛勢初篩 v0.2

這是一份 GeoLibre 專案，用於篩選宜蘭縣既有住宅中值得優先進一步做能效／碳排查核的區域。

## 圖層
1. **綜合碳排風險潛勢初篩（預設顯示）**
   - 65% × 30年以上住宅占比（min-max 正規化）
   - 35% × 30年以上住宅宅數（min-max 正規化）
2. **30年以上住宅占比（對照層，預設關閉）**

## 資料期別
- 鄉鎮市空間基線：108 年底（2019）宜蘭縣住宅屋齡結構。
- 縣級現況參考：2025 Q2，平均屋齡 35.0 年；30 年以上住宅 123,027 宅，占 60.5%。

## 重要限制
- **這不是實際碳排量，也不是官方 BERS / BERSe 評分。**
- 最終建物級模型應以 **1998 年以前**為第一層重點，**1995 年以前**標為最高年代風險群。
- 下一階段應加入：使用執照日期、樓地板面積、建築用途、構造、樓層、熱環境，以及可取得時的實際用電。
