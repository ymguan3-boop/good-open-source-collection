# 好用開源程式收集

個人收集的好用開源程式。

## 目錄

- `上帝之眼/` — 來自 https://github.com/bilawalsidhu/gods-eye-view （MIT, 原作者 Bilawal Sidhu）
  - 瀏覽器中的間諜衛星模擬器：真實資料的即時開源空間情報，照片級寫實 3D 地球儀。
  - 版本：2026-09-18 同步的最新版（shallow clone, 去除 .git 歷史）
  - 詳細說明請看 `上帝之眼/README.md`（原專案 README）與 `上帝之眼/來源說明.md`
- `GeoLibre/` — 來自 https://github.com/opengeos/GeoLibre （MIT, opengeos）
  - 輕量雲端原生 GIS：瀏覽器、桌面、手機、Jupyter 皆可跑，1,000+ 地理處理工具。
  - 版本：2026-09-24 同步的最新版（shallow clone, 去除 .git 歷史，7,617 星）
  - 詳細說明請看 `GeoLibre/來源說明.md`
