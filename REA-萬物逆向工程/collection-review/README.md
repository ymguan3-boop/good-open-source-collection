### 人工複核的疑似私鑰

`third_party/binwalk/src/signatures/pem.rs` 中的 `-----BEGIN PRIVATE KEY-----` 等字串是 Binwalk 用來比對 PEM 格式的固定標頭，不是私鑰內容。此排除僅限特定原始檔中的字面值，其餘目錄仍維持敏感資訊掃描。

### 已知依賴風險

`fast-uri` 的鎖定相依版本受到中度風險公告影響（包括 GHSA-w74x-v6f9-j3xg、GHSA-wjr9-j795-jxcr，見 `npm-production-audit.json`）。已存在修正版本；為忠實保存上游快照，這份備份不擅自修改其依賴版本。**實際安裝或提供服務前，應重新執行 npm audit、確認相依升級與兼容性。**

### 需要特別注意的能力

全樹掃描發現 shell/子程序執行、動態程式碼、網路請求、下載後執行命令及檔案刪除等模式。這些可能來自逆向分析工具的正常功能、測試碼、文件或第三方安裝腳本，**不是直接證明惡意**；但也不能僅依字串掃描就斷言完全無害。建議只在受控權限的環境執行，避免對重要主機直接執行 `curl ... | bash` 及未知的安裝腳本，並限制可讀取的金鑰、私有專案與網路存取權限。
