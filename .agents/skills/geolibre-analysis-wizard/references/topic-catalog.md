# GeoLibre 分析主題與建議題庫

本檔供 `geolibre-analysis-wizard` 在使用者「沒有想法」時提供題目。
題目不是固定模板；應依使用者指定縣市、時間與資料可取得性調整。

## 1. 水利與排水

1. 找出指定區域最近 5 年淹水點 100 公尺內，又位於局部低窪地區，而且鄰近雨水下水道的道路。
2. 找出歷史重複淹水熱點與雨水下水道末端、低坡度或可能排水瓶頸重疊的區域，並列出附近重要道路。
3. 找出學校、醫院、消防據點周邊 300 公尺內，歷史淹水頻繁且地勢相對低窪的公共設施。
4. 比較不同鄉鎮市淹水點密度、排水設施密度與地形高程，找出排水服務相對弱的區域。

## 2. 災害防救

1. 找出歷史災害點周邊 500 公尺內，同時具有高人口、重要設施且逃生路線單一的區域。
2. 找出土石流、淹水或坡地災害可能影響的學校、醫院與避難處所，建立優先巡查清單。
3. 以災害點、地形、道路與避難設施建立多因子風險分數，標示高風險村里。
4. 找出災害事件發生後可能因道路中斷而形成孤島效應的聚落。

## 3. 大地工程與邊坡

1. 找出坡度較陡、鄰近地質敏感區且道路下方或上方有建物的山區道路。
2. 找出歷史崩塌點 200 公尺內、坡度高於門檻且鄰近道路的邊坡路段。
3. 找出新建工程基地周邊可能受到邊坡、地質、排水及高程差共同影響的區域。
4. 依坡度、地質、坡向、道路切坡與災害紀錄建立邊坡巡查優先順序。

## 4. 道路養護

1. 找出歷史淹水、低窪、下水道鄰近且道路等級較高的優先巡查道路。
2. 找出道路挖掘案件密集、重複開挖或鄰近多種地下管線的道路。
3. 找出人孔蓋密度高、道路寬度較小、事故或陳情較多的道路。
4. 將坑洞/修補/挖掘紀錄與交通量、降雨、地形交叉分析，建立養護風險分數。

## 5. 交通安全

1. 找出交通事故熱點 100 公尺內，同時鄰近學校、市場或高齡人口聚落的道路。
2. 找出急彎、陡坡、視距受限且事故曾發生的山區道路。
3. 找出行人事故集中且人行道不足、路口密度高或公共運輸站點密集的區域。
4. 比較道路幾何、速限、路口、照明與事故資料，找出高風險路段。

## 6. 河川與橋梁

1. 找出跨河橋梁中，鄰近沖刷、淹水或高流速河段且替代道路距離較遠者。
2. 找出橋梁上下游一定距離內河道彎曲、河寬變化大或歷史災害較多的橋梁。
3. 找出重要道路橋梁周邊淹水點、地勢低窪與人口/公共設施集中的位置。
4. 依橋齡、河川風險、交通重要度與替代性建立橋梁巡查優先排序。

## 7. 建築、危老與耐震

1. 找出老舊建物集中且鄰近活動斷層、土壤液化或地質敏感區的街廓。
2. 找出高齡人口較多、老舊建物密度高且消防救災動線較差的區域。
3. 找出公共建築、學校或醫療設施位於複合地質風險區的案件。
4. 將建築年代、樓層、用途、地質與道路可達性建立耐震/救災優先盤點圖。

## 8. 地質與地質敏感

1. 找出道路、學校或公共設施與山崩地滑、活動斷層、地下水補注等地質敏感區重疊的位置。
2. 找出開發基地周邊 500 公尺內同時存在多種地質敏感因子的區域。
3. 找出地質敏感區內坡度高、建物密集且鄰近道路的高暴露區。
4. 比較現有開發分布與地質敏感區，找出優先檢核的建築或工程案件。

## 9. 都市計畫與土地使用

1. 找出都市計畫土地使用與現況建物/道路使用可能不一致的區域。
2. 找出公共設施用地服務範圍不足、人口密度較高的生活圈。
3. 找出新開發區周邊道路容量、公共設施、排水與災害風險可能不足的區域。
4. 依土地使用、人口、交通與公共設施進行選址適宜性分析。

## 10. 公共管線

1. 找出同一路段地下管線種類多、挖掘頻繁且道路重要度高的道路。
2. 找出管線資料斷裂、未相連、屬性缺漏或與實際道路位置可能不一致的異常區。
3. 找出重要公共設施周邊高密度管線交會區，作為施工與災害風險盤點。
4. 將道路挖掘、管線種類、竣工日期與重複開挖次數建立施工協調優先清單。

## 11. 環境與生態

1. 找出開發基地周邊一定範圍內與河川、濕地、保育區或生態敏感區重疊的位置。
2. 找出道路或工程可能切割綠地、生態廊道或重要棲地的區域。
3. 比較土地利用變遷與綠覆率，找出快速都市化且綠地減少的區域。
4. 以水體、綠地、坡度、人口與熱環境資料建立環境敏感度圖。

## 12. 海岸與沿海風險

1. 找出低海拔沿海道路與歷史淹水、暴潮或海岸侵蝕風險重疊的位置。
2. 找出沿海重要公共設施位於低窪區且替代聯外道路不足者。
3. 找出海岸線變遷較大、鄰近道路或建物的侵蝕敏感區。
4. 以高程、距海岸、土地使用與災害紀錄建立沿海風險分區。

## 13. 農業、坡地與灌溉

1. 找出坡地農業區中坡度高、鄰近崩塌或土石流風險且有道路進出的區域。
2. 找出灌溉渠道服務範圍與農地分布不一致或距離過遠的農地。
3. 找出農地周邊淹水頻繁、排水不足且地勢低窪的區域。
4. 比較農地變更、道路開闢與坡度，找出可能需要優先查核的山坡地利用。

## 14. 消防、避難與救災

1. 找出消防分隊服務時間較長、人口密集且災害風險較高的區域。
2. 找出避難收容處所服務半徑不足或跨越高風險道路/河川的聚落。
3. 找出醫院、長照、學校等脆弱設施中，聯外道路替代性低的地點。
4. 以路網可達性模擬災害道路中斷後的救災服務缺口。

## 15. 公共設施、學校與醫療

1. 找出學校、醫院、長照或政府機關位於淹水、地質或交通複合風險區的位置。
2. 找出公共設施服務範圍重疊不足、人口集中但步行可達性差的區域。
3. 找出學校周邊交通事故、淹水或人行環境風險較高的道路。
4. 以公共設施重要度與災害暴露建立優先改善清單。

## 16. 淨零、碳排與綠地

1. 找出建物密集、綠覆率低、公共運輸可達性差的高碳依賴區域。
2. 找出適合新增綠地、滯洪或都市降溫設施的候選基地。
3. 比較公共設施、道路、建築與土地使用，建立開發案空間碳風險指標。
4. 找出可透過步行、自行車或公共運輸改善降低短程汽車依賴的生活圈。

## 題目產生規則

若使用者指定「宜蘭縣」，優先把題目具體化為宜蘭可取得資料；
若指定其他縣市，替換行政區並重新確認資料來源可用性。

不要只給抽象題目，例如「分析水利風險」。
必須寫成可以直接轉成圖層與空間條件的句子。
