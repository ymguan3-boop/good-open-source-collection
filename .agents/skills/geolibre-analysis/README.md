# Canonical Codex GeoLibre Skill

Use this directory as the single project-level Codex skill for guided GeoLibre GIS analysis:

`.agents/skills/geolibre-analysis/`

It covers:
- first-use GeoLibre GitHub binding/onboarding,
- idea discovery through a 17-topic catalog,
- progressive GIS specification,
- explicit confirmation before execution,
- reproducible GitHub/Python/GeoLibre analysis,
- public GeoLibre map,
- real GeoLibre screenshots when browser automation is available,
- XLSX, GeoJSON, summary, report and QA.

The upstream/bottom-level GeoLibre capability skill remains at:

`GeoLibre/skills/geolibre/`

That upstream skill is a technical reference for GeoLibre authoring/MCP/embed capabilities.
It is not a second copy of this guided analysis workflow.
